작업 분량 규칙
• 작업이 커서 한 대화에서 끝내기 어려우면 적당한 단위로 끊어 저장
• 끊을 때 CLAUDE_HANDOFF.md에 '진행 중' 표기와 완료 항목·남은 항목을 기록하고 종료, 다음 대화에서 그 기록부터 이어서 진행
• 한꺼번에 전부 하려다 결과물 없이 멈추는 것보다 일부라도 저장하는 것을 우선

금지 사항
• 게임 규칙·수치·판정 범위·피해·재사용·저장 데이터·자동 플레이 로직 변경 금지 (그리기·표시만 변경)
• 색만 바꾼 구분 금지: 외형·동작 자체로 구분
• 위험(적 공격 예고) 표시를 덮는 장식 금지, 개체 판정 크기와 화면 표시 크기 불일치 금지
• Claude 작업과 동시 진행 금지: 이 요청 처리 중에는 사용자가 Claude 작업을 보류함

동작 원칙
• 자연스럽고 몰입감 있는 동작: 준비 동작 → 실행 → 잔상·여운의 흐름, 정지 그림 깜빡임 수준 금지
• 직업 정체성 강조: 해당 직업이 쓰는 것처럼 보이는 외형·자세 (예: 전사는 묵직함, 도적은 날렵함, 시간술사는 시계·톱니 모티프)
• 작은 화면(320~390px 폭)에서 다수 적과 함께 있어도 식별 가능한 크기·대비

요청 항목
• G43-1 연성 카드 틀: 레벨업 선택지에 나오는 연성 카드 전용 틀 최종본
  - 구성: 이중 테두리 + 은은한 빛남(맥동) + 직업 색 하이라이트 + 모서리 직업 문양(art 1차 직업 문장 재사용 가능)
  - 일반 카드와 한눈에 구분, 레어 보상 느낌, 글자 가독성 유지
  - 적용 위치: src/v43.js choiceCard 감싸기·style 블록, src/select-art.js
• G43-5 · G45-1 상단 화면(HUD) 최종 외형 (배치·동작은 현재 그대로 유지)
  - 상단 1단 패널: 왼쪽 위 직업 이름 + 기본 무기 칸, 페이즈 이름 + n/N 배지, 처치 수, 체력
  - 기본 무기 칸 직업 표식, 일반 무기 칸은 테두리 없음, 연성 무기 칸은 직업 색 단일 테두리 (이중 테두리 사용 안 함, 현재 코드의 이중 테두리도 단일 테두리로 교체)
  - 기본 무기 단독 발동 종료(무기 칸 전부 연성) 시 기본 무기 칸 어둡게 처리
  - 보스전: 보조 효과 줄 접힘 → 보스 체력 막대 전환 연출, 보스 체력 막대 최종 외형
  - 일시정지 버튼: 상단 패널과 일체감 있는 외형
  - 적용 위치: src/v45.js drawHUD·drawSlots·drawBossBar·style 블록, src/v43.js drawSlots 감싸기, src/ui-art.js drawSlots
• 참고: 기기별 상단 화면 비율(폴드·일반 폰) 조정은 사용자가 별도로 Claude에 요청 예정 → 이번 작업에서는 크기·배치 계산 변경 금지, 외형만
• 확인: 320px·390px 폭 캡처로 글자 겹침·잘림 없음 확인
