[도트 원본 그림 요청 D02] 도적 원본 그림
작성 2026-11-28 회차 100 (Claude)

1. 이 작업의 배경

• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
  - 플레이어는 이동만 조작하고, 공격은 자동으로 나감
  - 밝은 판타지 모험 분위기 (검과 마법, 마왕성), 보스나 특정 구간에서만 어두워짐
  - 이야기: 용사가 존재째 지워지고 망토만 남음 → 원정대 동료 8명 중 한 명이 그 망토를 이어받아 싸움
• 현재 진행: Claude(다른 AI)가 게임 제작을 맡고 있고, 지금은 밸런스 작업 중
• 너(GPT)의 역할: 게임 그래픽을 전부 도트(픽셀 아트)로 바꾸기 위한 '디자인 원본 그림'을 그리는 일
  - 네 그림을 Claude가 보고 정해진 칸 크기의 진짜 도트로 다시 찍음
  - 그래서 완벽한 도트일 필요는 없지만, 모양·색·분위기가 분명하게 보여야 함
  - 코드는 절대 건드리지 않음. 그림만 그려서 정해진 폴더에 저장하면 끝
• 화풍 기준은 광전사 그림(D01)
  - 작업 시작 전 assets/dot-src/berserker/ 에 sheet_capeA.png 등 광전사 원본이 저장되어 있으면 먼저 보고 화풍(칸 굵기·외곽선·명암·등신)을 맞출 것
  - 아직 없으면 아래 3장 화풍 규칙만 따라 그림 (광전사와 같은 규칙)

2. 그릴 인물: 도적

• 한 줄 정체성: 빠른 암살자. 본인은 거의 움직이지 않고, 발밑 그림자가 튀어나와 대신 벤다
• 무기: 한 손 단검 1자루 (기본). 허리·다리에 쿠나이(고리 손잡이 단도), 부적 몇 장 정도의 닌자 도구를 작게 달아도 됨
• 특징 (그림으로 보여야 하는 것)
  - 치명타가 나면 도적 그림자가 땅에서 솟아 같은 동작으로 한 번 더 그음
  - 그림자 = 도적과 같은 윤곽의 짙은 남색 형체, 눈 자리만 청록으로 빛남
  - 적에게는 붉은 상처 선이 남았다가 뒤늦게 터지는 연출이 있음
• 체형·성별·나이·얼굴은 정하지 않았음 → 컨셉에 맞게 네가 제안
  - 날렵하고 가벼운 체형, 몸에 붙는 옷과 가죽 장비 (무거운 갑옷 금지)
  - 두건(후드)을 씀: 게임 안 다른 그림(도적 두건을 두른 대역 통나무)과 이어지는 핵심 특징
  - 얼굴이 있는 사람으로 그림. 입가를 천으로 가리는 것은 괜찮지만 눈과 표정은 보이게
• 색 (게임 전체 규칙, 반드시 지킬 것)
  - 주색 그림자 남색 #1B1F2E: 가장 넓은 면적 (옷·두건)
  - 보조색 남회색 #3A4250: 테두리·그림자·밝은 면 쪽 옷 주름
  - 포인트색 청록 #2FC4B2: 단검 날빛·눈빛·장식 등 아주 작게
  - 피부·머리카락·가죽·금속 등 필요한 색은 추가해도 되지만, 전체 인상은 위 3색이 주도
  - 주의: 주색이 매우 어두움 → 회색 배경 위에서 몸이 뭉개지지 않게, 남회색 밝은 면과 피부·가죽색으로 윤곽을 분명하게
• 망토: 모든 인물이 망토를 걸침, 망토 색은 인물마다 그 인물 색에 어울리게 다름, 찢어진 모양 금지
  - 이야기상 '용사의 진홍 망토를 이어받아 자기 색으로 물든 것'
  - 도적 망토는 위 3색 계열 안에서 몸·옷과 구분되게 (예: 남회색 바탕 + 청록 테두리, 짧은 어깨 망토 등)
  - 망토 디자인 2안(A·B)을 그려서 비교: 길이·색 배치·장식을 서로 다르게, 네가 제안
  - 망토와 두건이 한 덩어리로 이어진 안도 가능 (단, 두건은 두 안 모두 있음)
  - 붉은 계열(광전사)·보라 계열(사령술사)·자홍(분홍 보라)으로 치우치지 않게 주의

3. 화풍 규칙 (D01과 동일)

• 도트 그림(픽셀 아트) 느낌: 굵고 분명한 칸, 칸 경계가 또렷하게
• 흐림·부드러운 그라데이션·광택·사진 같은 질감 금지
• 색 수를 적게: 인물 한 명당 약 16색 이내
• 외곽선은 순수한 검은색 대신 짙은 색(보조색 등)을 사용
• 시점: 정면에서 살짝 위에서 내려다본 시점 (위에서 내려다보는 2D 게임 캐릭터처럼, 머리와 몸 앞면이 다 보임)
• 등신: 약 2.5등신, 머리 = 몸 높이의 약 40%
• 최종 도트 크기는 인물 40×40칸 → 40칸으로 줄여도 두건·단검·망토가 알아보이는 굵은 모양으로 디자인
• 실루엣: 검은색으로 채워도 도적인지 알아볼 수 있게 (두건 모양·단검·망토로 구분)
• 배경: 무늬 없는 단색 회색 #808080 (나중에 오려 내기 쉽도록)
• 금지
  - 자홍색(분홍 보라) 계열: 게임에서 적 공격 예고 전용 색
  - 순수한 흰색·순수한 검은색을 넓게 쓰는 것
  - 그림 안에 글자·로고·서명
  - 기존 게임이나 만화의 특정 캐릭터(유명 닌자·암살자 캐릭터 등)와 닮게 그리는 것
• 도트 규칙 문서 docs/DOT_STYLE.md 의 1·2·4장(시점·빛 방향 왼쪽 위·외곽선·명암 3단계·비율)을 원본 그림에도 맞춰 줄 것

4. 그릴 그림 (총 4장)

• 그림 1~2: 전신 설정화 (망토 A안·B안 각각 1장)
  - 한 장 안에 같은 인물을 3방향으로: 앞(아래쪽을 봄) / 옆(오른쪽을 봄) / 뒤(위쪽을 봄)
  - 단검을 낮게 쥔 기본 자세, 망토는 뒤 방향 그림에서 잘 보이게
  - 두 장은 망토만 다르고 나머지는 같게
• 그림 3: 그림자 연격 장면 1장 (망토 A안, 앞 방향)
  - 도적 본인은 거의 그대로 선 자세
  - 발밑 그림자에서 솟은 그림자 형체가 단검으로 크게 긋는 순간 (그림자 형체 = 도적 윤곽, 짙은 남색, 눈만 청록)
  - 그림자 형체는 반투명 대신 '짙은 단색 + 남회색 가장자리'로 표현 (도트에서 반투명 금지)
• 그림 4: 상반신 초상 (망토 A안 기준)
  - 가슴 위까지, 정면에서 살짝 비스듬히, 표정은 차갑고 침착하게, 눈빛에 청록 포인트
  - 이 그림은 나중에 160×160칸 도트 초상화의 원본이 됨

5. 저장 규칙

• 저장소: GitHub 1hyun-you/loop-game, main 브랜치
• 저장 폴더: assets/dot-src/rogue/ 만 사용 (다른 폴더·파일은 절대 수정하지 않음)
• 파일 형식: PNG, 가로 512칸 정도로 줄여서 저장, 한 장 0.5MB 이하
• 파일 이름
  - sheet_capeA.png, sheet_capeB.png
  - pose_shadow.png
  - portrait.png
• 같은 폴더에 note.md 1개 작성: 사용한 주요 색 번호, 외형 설명 3~5줄, 망토 장식 설명, 그림자 형체 표현 방식 1줄
• 커밋 메시지 앞에 [skip deploy] 를 붙임 (예: [skip deploy] D02 도적 도트 원본 4장)
• 다른 대화창(광전사 D01 등)도 동시에 다른 폴더에 저장할 수 있음
  - 저장(push)이 거절되면 최신 내용을 받은 뒤(pull) 다시 저장하면 됨
  - 다른 폴더 파일이 바뀌어 있어도 건드리지 말 것
