[도트 제작 요청 묶음 O2] 아이콘 — 연성 무기 14개 (광전사 · 도적)
작성 2026-11-28 회차 104 (Claude)

1. 배경
• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
• 그래픽은 모두 도트로 전환 중이고, 도트는 네가 원화 없이 정해진 칸 수로 직접 찍는 방식으로 확정됨
• 이번 묶음: 광전사 · 도적의 연성 무기 아이콘 14개 (레벨업 연성 카드·전투 화면 위쪽 칸에 쓰임)
• 진행 방식: 인물 1명(7개) 완성 → 저장·커밋 → 다음 (중간에 끊겨도 완성분은 남게)
• 코드는 절대 건드리지 않음. 그림만 지정 폴더에 저장하면 끝

2. 참고 파일
• 화풍 기준: assets/dot-src/berserker/gpt_dot/ (외곽선·명암·면 나누기를 같게)
• 도트 규칙: docs/DOT_STYLE.md
• 인물 그림: assets/dot-src/berserker, rogue/gpt_dot/ / 소환·설치물 그림이 이미 있으면 assets/dot-src/summons/, engineer/machines/, necromancer/summons/ 모양을 따름 / 같은 규격 예: assets/dot-src/icons/base/ (있으면 화풍 맞춤)

3. 도트 규격
• 정확히 32×32 PNG, 투명 배경, 12색 이내
• 사방 2칸 여백, 그림은 가운데, 비스듬히 45도로 놓은 구도 우선(칼·화살 등)
• 테두리·카드 틀·배경 원은 그리지 않음 (게임 코드가 그림)
• 게임 화면에서 28점 크기 칸에 1배로, 카드에서는 2·3배로 표시됨 → 1배에서도 무엇인지 읽히게 굵고 단순한 형태, 세부 장식 최소
• 픽셀 1개 = 도트 1칸, 흐림·중간색 경계·반투명 금지, 글자·숫자·로고 금지
• 외곽선 바깥 1칸 가장 짙은 색(순수 검정 금지), 빛 왼쪽 위, 명암 3단계
• 자홍(분홍 보라) 금지 (적 공격 예고 전용)

4. 연성 아이콘 공통
• 연성 = 인물의 전용 무기와 다른 무기(짝 무기)를 합친 강화 무기 → 아이콘은 '그 인물이 쓰는 짝 무기' 모습
• 그 인물 색 3색을 주로 쓰고, 짝 무기를 알아볼 모양(대검·단검·활·포탑·불덩이·등불·종·덩굴)이 보이게
• 한 인물 7개는 색이 같으므로 실루엣이 서로 확실히 다르게

5. 대상 (영문 이름 = 파일 이름)
• 광전사 연성 7 (색: 진홍 #D23A2E·검붉은 #5A1414·살구 #FFB38A)
  - f_b_slash 칼자국 (단검 + 대검): 굵게 찢긴 붉은 칼자국 3줄 + 작은 단검
  - f_b_arrow 투기살 (장궁 + 대검): 붉은 투기 한 줄기 화살이 길게 꿰뚫는 모양
  - f_b_grave 칼무덤 (포탑 + 대검): 땅에 꽂힌 대검 + 그 둘레 붉은 반원 돔 선
  - f_b_erupt 분화 (화염구 + 대검): 갈라진 땅 틈에서 솟는 불덩이
  - f_b_thirst 피의 갈증 (영혼 등불 + 대검): 대검으로 빨려 드는 붉은 줄기 3가닥
  - f_b_pulse 고동 (축복의 종 + 대검): 붉은 심장 모양 + 겹친 고리 2개
  - f_b_spike 투기 가시 (가시 덩굴 + 대검): 땅에서 솟은 붉은 가시 3개
• 도적 연성 7 (색: 그림자 남색 #1B1F2E·남회 #3A4250·청록 #2FC4B2)
  - f_r_wind 흑풍 (대검 + 단검): 그림자가 부채꼴로 휩쓰는 검은 바람
  - f_r_star 그림자 표창 (장궁 + 단검): 네 날 별 모양 표창 + 회전 잔상
  - f_r_log 대역 통나무 (포탑 + 단검): 두건 두른 가시 통나무
  - f_r_kunai 기폭찰 쿠나이 (화염구 + 단검): 부적 붙은 쿠나이(고리 손잡이 단도), 부적 끝 불씨
  - f_r_thief 그림자 도둑 (영혼 등불 + 단검): 단검 끝에서 이어진 그림자 실
  - f_r_ripple 숨죽인 파문 (축복의 종 + 단검): 어두운 겹 물결 고리 + 가운데 단검
  - f_r_snare 올가미 (가시 덩굴 + 단검): 청록 매듭이 있는 그림자 줄 올가미
