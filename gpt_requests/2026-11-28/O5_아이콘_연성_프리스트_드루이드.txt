[도트 제작 요청 묶음 O5] 아이콘 — 연성 무기 14개 (프리스트 · 드루이드)
작성 2026-11-28 회차 104 (Claude)

1. 배경
• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
• 그래픽은 모두 도트로 전환 중이고, 도트는 네가 원화 없이 정해진 칸 수로 직접 찍는 방식으로 확정됨
• 이번 묶음: 프리스트 · 드루이드의 연성 무기 아이콘 14개 (레벨업 연성 카드·전투 화면 위쪽 칸에 쓰임)
• 진행 방식: 인물 1명(7개) 완성 → 저장·커밋 → 다음 (중간에 끊겨도 완성분은 남게)
• 코드는 절대 건드리지 않음. 그림만 지정 폴더에 저장하면 끝

2. 참고 파일
• 화풍 기준: assets/dot-src/berserker/gpt_dot/ (외곽선·명암·면 나누기를 같게)
• 도트 규칙: docs/DOT_STYLE.md
• 인물 그림: assets/dot-src/priest, druid/gpt_dot/ / 소환·설치물 그림이 이미 있으면 assets/dot-src/summons/, engineer/machines/, necromancer/summons/ 모양을 따름 / 같은 규격 예: assets/dot-src/icons/base/ (있으면 화풍 맞춤)

3. 도트 규격
• 정확히 32×32 PNG, 투명 배경, 12색 이내
• 사방 2칸 여백, 그림은 가운데, 비스듬히 45도로 놓은 구도 우선(칼·화살 등)
• 테두리·카드 틀·배경 원은 그리지 않음 (게임 코드가 그림)
• 게임 화면에서 28점 크기 칸에 1배로, 카드에서는 2·3배로 표시됨 → 1배에서도 무엇인지 읽히게 굵고 단순한 형태, 세부 장식 최소
• 픽셀 1개 = 도트 1칸, 흐림·중간색 경계·반투명 금지, 글자·숫자·로고 금지
• 외곽선 바깥 1칸 가장 짙은 색(순수 검정 금지), 빛 왼쪽 위, 명암 3단계
• 자홍(분홍 보라) 금지 (적 공격 예고 전용)

4. 연성 아이콘 공통
• 연성 = 인물의 전용 무기와 다른 무기(짝 무기)를 합친 강화 무기 → 아이콘은 '그 인물이 쓰는 짝 무기' 모습
• 그 인물 색 3색을 주로 쓰고, 짝 무기를 알아볼 모양(대검·단검·활·포탑·불덩이·등불·종·덩굴)이 보이게
• 한 인물 7개는 색이 같으므로 실루엣이 서로 확실히 다르게

5. 대상 (영문 이름 = 파일 이름)
• 프리스트 연성 7 (색: 금 #E8C35A·흰빛 #FFF8E7·옅은 하늘 #A8D8FF — 7개 모두 금빛이므로 모양으로 구분, 실제 종교 상징·날개 금지)
  - f_q_sword 성검 (대검 + 축복의 종): 빛의 검
  - f_q_cross 십자 긋기 (단검 + 축복의 종): 세로·가로 빛 칼금 (가로 획이 더 김)
  - f_q_prism 갈라지는 빛살 (장궁 + 축복의 종): 빛 화살 끝에서 두 갈래로 갈라지는 빛살
  - f_q_candle 금빛 촛대 (포탑 + 축복의 종): 세 갈래 금 촛대
  - f_q_flame 성화 (화염구 + 축복의 종): 흰 불꽃 덩이
  - f_q_lamp 정화의 등불 (영혼 등불 + 축복의 종): 금빛 등불 안 흰빛 + 빨려 드는 검은 점
  - f_q_chain 결박진 (가시 덩굴 + 축복의 종): 빛 문양 원 + 솟은 빛 사슬
• 드루이드 연성 7 (색: 짙은 초록 #2E6B34·나무 갈색 #6B4A2B·꽃가루 노랑 #E6D86A — 불 금지)
  - f_d_claw 앞발 휩쓸기 (대검 + 가시 덩굴): 짐승 발톱 자국 3줄 두 번
  - f_d_leaf 칼잎 (단검 + 가시 덩굴): 날카로운 칼잎 3장
  - f_d_hawk 매 강하 (장궁 + 가시 덩굴): 날개 접고 내리꽂는 매
  - f_d_flytrap 식충 꽃 (포탑 + 가시 덩굴): 입 벌린 초록 꽃봉오리
  - f_d_spore 포자 버섯 (화염구 + 가시 덩굴): 갈색·초록 점박이 큰 버섯
  - f_d_root 생명 뿌리 (영혼 등불 + 가시 덩굴): 땅속으로 뻗는 뿌리 두 가닥
  - f_d_bellflower 초롱꽃 (축복의 종 + 가시 덩굴): 종 모양 연노랑 꽃 3송이
