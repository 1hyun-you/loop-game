[도트 원본 그림 요청 D01] 광전사 기준 그림 (전체 화풍 기준)
개정 2026-11-28 회차 100: 칸 수 40칸·초상화 160칸·등신 2.5 반영, 그림 구성 정리

1. 이 작업의 배경

• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
  - 플레이어는 이동만 조작하고, 공격은 자동으로 나감
  - 밝은 판타지 모험 분위기 (검과 마법, 마왕성), 보스나 특정 구간에서만 어두워짐
  - 이야기: 용사가 존재째 지워지고 망토만 남음 → 원정대 동료 8명 중 한 명이 그 망토를 이어받아 싸움
• 현재 진행: Claude(다른 AI)가 게임 제작을 맡고 있고, 지금은 밸런스 작업 중
• 너(GPT)의 역할: 게임 그래픽을 전부 도트(픽셀 아트)로 바꾸기 위한 '디자인 원본 그림'을 그리는 일
  - 네 그림을 Claude가 보고 정해진 칸 크기의 진짜 도트로 다시 찍음
  - 그래서 완벽한 도트일 필요는 없지만, 모양·색·분위기가 분명하게 보여야 함
  - 코드는 절대 건드리지 않음. 그림만 그려서 정해진 폴더에 저장하면 끝
• 이번 그림은 앞으로 나올 모든 그림의 화풍 기준이 됨. 사용자가 여러 안 중에서 고를 예정
• Claude가 먼저 찍은 32칸 도트 초안이 있음: assets/dot-src/berserker/claude_ref/ (sheet_preview.png 먼저 볼 것)
  - 시점·색 배치 참고용일 뿐, 디자인은 따라 하지 않아도 됨 (사용자는 이 초안이 마음에 들지 않음)
  - 초안은 옛 크기(32칸), 최종 도트 크기는 인물 40×40칸 → 40칸으로 줄여도 머리·대검·망토가 알아보이는 굵은 모양으로 디자인
  - 네가 더 멋지고 완성도 높은 광전사를 새로 디자인할 것

2. 그릴 인물: 광전사

• 한 줄 정체성: 분노로 날뛰는 근접 전사
• 무기: 양손으로 드는 큰 대검. 앞쪽 부채꼴로 크게 베어 적을 밀쳐 냄
• 특징: 맞을수록 분노가 쌓이고, 가득 차면 '격노' 상태가 되어 몸에 붉은 불길이 일렁임
• 체형·성별·나이·얼굴은 정하지 않았음 → 컨셉에 맞게 네가 제안
  - 거칠고 힘이 넘치는 인상, 가벼운 경갑 정도 (전신 판금 갑옷은 피함)
  - 얼굴이 있는 사람으로 그림 (가면·얼굴 없는 형체 아님)
• 색 (게임 전체 규칙, 반드시 지킬 것)
  - 주색 붉은색 #D23A2E: 가장 넓은 면적
  - 보조색 검붉은색 #5A1414: 테두리·그림자
  - 포인트색 열기 살구 #FFB38A: 번쩍이는 곳·핵심부만 작게
  - 피부·머리카락·금속 등 필요한 색은 추가해도 되지만, 전체 인상은 위 3색이 주도
• 망토: 모든 인물이 망토를 걸침, 망토 색은 인물마다 그 인물 색에 어울리게 다름, 찢어진 모양 금지
  - 이야기상 '용사의 진홍 망토를 이어받아 자기 색으로 물든 것'
  - 광전사 망토는 위 3색 계열 안에서 몸·옷과 구분되게 (예: 짙은 검붉은 바탕 + 살구색 장식)
  - 망토 디자인 2안(A·B)을 그려서 비교: 색 배치·장식(예: 붉은 실 매듭, 이빨 장식 등)을 서로 다르게, 네가 제안
  - 자홍(분홍 보라) 쪽으로 치우치지 않게 주의

3. 화풍 규칙

• 도트 그림(픽셀 아트) 느낌: 굵고 분명한 칸, 칸 경계가 또렷하게
• 흐림·부드러운 그라데이션·광택·사진 같은 질감 금지
• 색 수를 적게: 인물 한 명당 약 16색 이내
• 외곽선은 순수한 검은색 대신 짙은 색(보조색 등)을 사용
• 시점: 정면에서 살짝 위에서 내려다본 시점 (위에서 내려다보는 2D 게임 캐릭터처럼, 머리와 몸 앞면이 다 보임)
• 등신: 약 2.5등신, 머리 = 몸 높이의 약 40% (작은 화면에서 표정·머리 모양이 보이도록)
• 실루엣: 검은색으로 채워도 광전사인지 알아볼 수 있게 (머리 모양·대검·망토로 구분)
• 배경: 무늬 없는 단색 회색 #808080 (나중에 오려 내기 쉽도록)
• 금지
  - 자홍색(분홍 보라) 계열: 게임에서 적 공격 예고 전용 색
  - 순수한 흰색·순수한 검은색을 넓게 쓰는 것
  - 그림 안에 글자·로고·서명
  - 기존 게임이나 만화의 특정 캐릭터와 닮게 그리는 것

4. 그릴 그림 (총 4장)

• 그림 1~2: 전신 설정화 (망토 A안·B안 각각 1장)
  - 한 장 안에 같은 인물을 3방향으로: 앞(아래쪽을 봄) / 옆(오른쪽을 봄) / 뒤(위쪽을 봄)
  - 대검을 든 기본 자세, 망토는 뒤 방향 그림에서 잘 보이게
  - 두 장은 망토만 다르고 나머지는 같게
• 그림 3: 같은 인물을 망토 A안으로, 대검을 앞쪽 부채꼴로 크게 휘두르는 순간의 자세 1장 (공격 자세 참고용, 앞 방향)
• 그림 4: 상반신 초상 (망토 A안 기준)
  - 가슴 위까지, 정면에서 살짝 비스듬히, 표정은 이를 악문 분노
  - 이 그림은 나중에 160×160칸 도트 초상화의 원본이 됨
• 도트 규칙 문서 docs/DOT_STYLE.md 의 1·2·4장(시점·빛 방향 왼쪽 위·외곽선·명암 3단계·비율)을 원본 그림에도 맞춰 줄 것

5. 저장 규칙

• 저장소: GitHub 1hyun-you/loop-game, main 브랜치
• 저장 폴더: assets/dot-src/berserker/ 만 사용 (다른 폴더·파일은 절대 수정하지 않음)
• 파일 형식: PNG, 가로 512칸 정도로 줄여서 저장, 한 장 0.5MB 이하
• 파일 이름
  - sheet_capeA.png, sheet_capeB.png
  - pose_attack.png
  - portrait.png
• 같은 폴더에 note.md 1개 작성: 사용한 주요 색 번호, 외형 설명 3~5줄, 망토 장식 설명
• 커밋 메시지 앞에 [skip deploy] 를 붙임 (예: [skip deploy] D01 광전사 도트 원본 4장)
• 다른 대화창도 동시에 다른 폴더에 저장할 수 있음
  - 저장(push)이 거절되면 최신 내용을 받은 뒤(pull) 다시 저장하면 됨
  - 다른 폴더 파일이 바뀌어 있어도 건드리지 말 것
