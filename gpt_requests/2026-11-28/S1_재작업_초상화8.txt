1. 배경
• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
• 도트는 네가 정해진 칸 수로 원화 없이 직접 찍는 방식으로 확정됨
• 이번 묶음은 재작업: 사용자 평가 "멍청해 보이고 생기다 만 느낌". 구체 문제는 아래 5장에 대상별로 적음
• 진행 방식: 대상 하나씩 → 먼저 기준 장(아래 6장 '기준 장') 1장을 완성해 대화창에 보여 준 뒤 기다리지 말고 나머지 장을 이어서 → 저장·커밋 → 다음 대상
• 코드는 절대 건드리지 않음. 그림만 지정 폴더에 저장하면 끝

3. 도트 규격 (공통)
• 픽셀 1개 = 도트 1칸, 투명 배경, 흐림·중간색 경계·반투명 금지
• 색 수: 초상화 32색 이내
• 외곽선 바깥 1칸 가장 짙은 색(순수 검정 금지), 빛 왼쪽 위, 명암 3단계
• 시점: 정면에서 살짝 위에서 내려다본 2D 탑다운
• 바닥 줄: 맨 아래에서 3칸 위(64칸 = 60번 줄), 좌우 가운데 / 사방 2칸 이상 여백
• 자홍(분홍 보라) 금지(적 공격 예고 전용), 글자·로고 금지
• 실루엣만으로 구분 가능, 색만 바꾼 구분 금지

4. 얼굴 규칙 (160칸 초상화 기준 칸 수)
• 지금 문제: 8명이 같은 얼굴 틀(반쯤 감긴 눈 + 한쪽으로 비웃는 입)을 복사함, 피부 얼룩, 성별·나이 구분 안 됨, 사령술사는 인터넷 밈 같은 얼굴 → 8명 모두 얼굴형·눈·표정을 따로 설계
• 구도: 상반신, 얼굴이 가운데, 머리 가로 70~80칸, 어깨까지, 약간 3/4 정면, 배경 투명 (테두리는 코드가 그림)
• 눈: 가로 8~10칸 × 세로 5~6칸, 흰자·눈동자·하이라이트 1칸, 위 눈꺼풀 선 1칸, 눈꺼풀이 눈동자를 반 이상 덮는 '반쯤 감긴 눈' 금지
• 눈썹: 가로 10~12칸, 두께 2칸, 인물별 기울기로 표정
• 입: 인물별 (아래), 비웃음·삐뚤어진 미소는 화염술사만 한쪽 입꼬리 2칸 올림 허용
• 피부: 4~5단계 면 나누기, 점·얼룩 금지, 코는 그림자 면, 턱선 그림자로 얼굴형을 분명히
• 젊은 여성 3명(궁수·프리스트·드루이드): 좁은 턱, 큰 눈, 속눈썹, 부드러운 볼 / 남성 4명: 각진 턱 / 도적: 복면이라 눈만

5. 대상별 설명 (파일 이름 = portrait_<인물>.png, 160×160)
• 광전사 (남, 20대 후반): 분노를 힘으로 바꾸는 거친 전사 / 붉은 뻗친 머리, V자 짙은 눈썹, 부릅뜬 눈(눈동자 작고 날카롭게), 이를 악문 입(윗니·아랫니 맞물림 보임), 왼뺨 흉터 / 어깨에 대검 손잡이 / 진홍 망토 / 피할 것: 웃는 얼굴
• 도적 (성별 드러나지 않음): 날렵한 암살자 / 남색 두건 + 코·입 가린 복면, 눈만 노출(가늘고 날카로운 청록 눈), 눈썹은 두건 그늘로 / 거꾸로 쥔 고리 단검 끝이 어깨 옆에 / 피할 것: 얼굴 노출
• 궁수 (여, 20대 초반): 멈춰 서서 한 발에 꿰뚫는 침착한 명사수 / 갈색 긴 포니테일(어깨 뒤로 넘어온 끝이 보이게), 연두 머리띠, 차분한 일자 눈썹, 초록 눈동자, 다문 입 / 등 화살통 깃 / 후드 내린 연두 망토 / 피할 것: 남자처럼 보이는 넓은 턱·볼 얼룩
• 엔지니어 (남, 40대): 무엇이든 만드는 듬직한 장인 / 이마 위로 올린 용접 고글(눈을 가리지 않음), 구레나룻부터 입 주변까지 갈색 수염, 굵은 눈썹, 웃음 주름 있는 눈(뜬 눈), 다문 입은 수염에 반쯤 가려짐 / 어깨 너머 큰 렌치 / 작업 앞치마 / 피할 것: 졸린 눈
• 사령술사 (남, 30대, 마름): 영혼을 거두는 음울한 술사 / 깊은 보라 후드, 창백한 회청 피부, 움푹한 볼(광대 아래 그림자 2칸), 다크서클, 청백 눈동자, 무표정한 일자 입 / 낡은 철 등불의 청백 불빛이 얼굴 아래를 비춤 / 작은 해골 장식 / 피할 것: 동그란 얼굴·밈처럼 웃는 표정·소녀처럼 보이는 얼굴
• 화염술사 (남, 20대 초반): 자신만만한 젊은 마법사 / 끝이 꺾인 주황 뾰족 모자, 짙은 적갈색 머리(모자 아래로 조금), 살구색 피부(옷·모자 주황과 확실히 구분), 치켜올린 눈썹, 한쪽 입꼬리 미소 / 불꽃 지팡이 / 피할 것: 피부·옷·모자가 같은 주황으로 묻힘
• 프리스트 (여, 20대 초반): 기도로 지키는 온화한 사제 / 금발, 흰 베일, 금 머리띠, 바깥이 살짝 내려간 온화한 눈썹, 하늘색 눈동자, 옅은 미소 / 해 모양 성표 / 피할 것: 실제 종교 상징·날개, 무표정
• 드루이드 (여, 20대 초반): 숲과 하나 된 야성의 수호자 / 짙은 갈색 머리, 작은 가지 뿔 2개(머리 폭보다 좁게), 잎 머리관, 노랑 눈동자, 양 볼 초록 문양 2줄, 결연한 눈썹 / 잎 망토 / 피할 것: 큰 사슴뿔·소년처럼 보이는 얼굴
