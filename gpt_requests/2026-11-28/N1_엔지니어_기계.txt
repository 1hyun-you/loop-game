[도트 제작 요청 묶음 N1] 엔지니어 기계 (포탑 5종 · 연성 기계 7종)
작성 2026-11-28 회차 104 (Claude)

1. 배경
• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
• 도트는 네가 정해진 칸 수로 원화 없이 직접 찍는 방식으로 확정됨
• 이번 묶음: 엔지니어가 땅에 설치하는 기계들. 엔지니어 본인 그림과 같은 소재(구리색 #B8652F·철회색 #5E6670·용접 파랑 #4FA8FF)로 '같은 사람이 만든 기계'로 보이게
• 진행 방식: 대상 하나씩 완성 → 저장·커밋 → 다음 대상 (중간에 끊겨도 완성분은 남게)
• 코드는 절대 건드리지 않음. 그림만 지정 폴더에 저장하면 끝

2. 참고 파일
• 화풍 기준: assets/dot-src/berserker/gpt_dot/ (외곽선·명암·면 나누기를 같게)
• 도트 규칙: docs/DOT_STYLE.md
• 기준 그림: assets/dot-src/engineer/gpt_dot/ (엔지니어 색·화풍), 같은 화면에서 함께 보이므로 크기 비교 필수

3. 도트 규격 (공통)
• 픽셀 1개 = 도트 1칸, 투명 배경(바닥 타일 제외), 흐림·중간색 경계·반투명 금지
• 색 수: 인물 16 · 잡몹 12 · 정예 12 · 우두머리 16 · 수문장·마왕 24 · 배경 조각 8 이내
• 외곽선 바깥 1칸 가장 짙은 색(순수 검정 금지), 빛 왼쪽 위, 명암 3단계
• 시점: 정면에서 살짝 위에서 내려다본 2D 탑다운
• 바닥 줄: 맨 아래에서 3칸 위(64칸 = 60번 줄), 좌우 가운데 / 날아다니는 적은 예외
• ★그림이 캔버스 가장자리에 닿거나 잘리지 않게 사방 2칸 이상 여백 (이번 검수에서 공격 장면 손·불꽃이 오른쪽 끝에서 잘림)
• 자홍(분홍 보라) 금지(적 공격 예고 전용), 글자·로고 금지
• 실루엣만으로 구분 가능, 색만 바꾼 구분 금지

4. 얼굴 공통 규칙 (얼굴이 있는 대상)
• 정면 양쪽 눈 같은 높이·좌우 대칭, 눈 뜬 상태(흰자·눈동자 모두 보임, 가로 한 줄 눈 금지), 사선 눈 금지
• 입은 다문 짧은 선 (벌린 입·이빨은 설명에 있을 때만)
• 표정은 눈썹 모양으로, 턱선 1칸 그림자로 얼굴이 둥글게 퍼지지 않게
• 적·보스는 귀엽거나 예쁘지 않게, 위압감 우선

5. 기계 공통
• 16색 이내, 바닥에 놓인 물건이므로 바닥 줄 = 맨 아래에서 3칸 위, 발밑 그림자 1줄
• 방향: 포탑류는 포신 방향만 다른 3장(오른쪽·아래·위, 왼쪽은 게임이 반전) — 몸체는 같은 그림, 포신만 돌아감 / 걸어 다니는 기계는 오른쪽 옆모습만
• 쏘는 불꽃·총알·폭발은 그리지 않음(코드가 그림), 쏠 때 반동 1장만
• 손으로 만든 공방 기계 느낌: 리벳, 볼트, 구리 배관, 덧댄 철판 / 미래형 매끈한 로봇·빛줄기·전기 금지

6. 대상·칸 수·장수 (칸 수는 Claude 결정 가안)
• 기본 포탑 48칸: 세 다리 받침 위 작은 포신 1개 / 방향 3 + 반동 1
• 쌍열 포탑 48칸: 포신 2개 나란히 / 방향 3 + 반동 1
• 대구경 포탑 48칸: 굵고 짧은 포신 1개, 포구가 나팔처럼 넓음 / 방향 3 + 반동 1
• 회전 기관포 56칸: 포신 6개 묶음 + 탄약 상자, 장갑판·노란 경고 줄무늬 / 방향 3 + 포신 회전 2장(오른쪽 방향만)
• 박격포 56칸: 하늘을 향한 굵은 통 + 받침, 장갑판·노란 경고 줄무늬 / 대기 1 + 발사 반동 1 (방향 없음)
• 대검 기계병 80칸: 두 다리로 걷는 땅딸막한 로봇이 큰 대검을 듦(광전사 대검과 같은 모양) / 걷기 4 + 베기 2 + 회전 베기 1
• 칼날 드론 24칸 + 충전대 40칸: 프로펠러 2개 + 앞에 단검 칼날 / 드론 비행 2, 충전대 1
• 쇠뇌 포대 56칸: 받침 위 큰 쇠뇌(장궁을 가로로 눕힌 모양) / 방향 3 + 발사 1
• 용광로 64칸: 굴뚝 달린 작은 화로, 앞 투입구에 쇳물 빛 / 대기 2(굴뚝 연기 모양만 바뀜)
• 용접 토치 기계 48칸: 다리 셋 받침 위 꺾인 팔 끝에 토치 / 방향 3
• 경보종 48칸: 쇠 기둥 위 종 + 망치 팔 / 대기 1 + 울림 1(망치가 종을 침)
• 철조망 발사기 56칸: 받침 위 철조망 감긴 원통 / 방향 3 + 발사 1
• 파일 이름: <기계>_<동작>_<방향>_<번호>.png (기계 = turret, twin, heavy, gatling, mortar, mechsword, drone, dock, ballista, furnace, torch, bell, wire)
• 피할 것: 화염(화염술사)·빛(프리스트) 소재, 엔지니어 색과 다른 색 계열
