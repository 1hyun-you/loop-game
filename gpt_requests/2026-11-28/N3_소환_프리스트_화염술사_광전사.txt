[도트 제작 요청 묶음 N3] 소환·설치물 — 프리스트 · 화염술사 · 광전사
작성 2026-11-28 회차 104 (Claude)

1. 배경
• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
• 도트는 네가 정해진 칸 수로 원화 없이 직접 찍는 방식으로 확정됨
• 이번 묶음: 프리스트(여신 형상·대종·촛대), 화염술사(정령·등불·불꽃 대검), 광전사(칼무덤 칼)가 불러내거나 세우는 것
• 진행 방식: 대상 하나씩 완성 → 저장·커밋 → 다음 대상 (중간에 끊겨도 완성분은 남게)
• 코드는 절대 건드리지 않음. 그림만 지정 폴더에 저장하면 끝

2. 참고 파일
• 화풍 기준: assets/dot-src/berserker/gpt_dot/ (외곽선·명암·면 나누기를 같게)
• 도트 규칙: docs/DOT_STYLE.md
• 기준 그림: assets/dot-src/priest/gpt_dot/, pyromancer/gpt_dot/, berserker/gpt_dot/ (각 인물 색·화풍), 크기 비교 필수

3. 도트 규격 (공통)
• 픽셀 1개 = 도트 1칸, 투명 배경(바닥 타일 제외), 흐림·중간색 경계·반투명 금지
• 색 수: 인물 16 · 잡몹 12 · 정예 12 · 우두머리 16 · 수문장·마왕 24 · 배경 조각 8 이내
• 외곽선 바깥 1칸 가장 짙은 색(순수 검정 금지), 빛 왼쪽 위, 명암 3단계
• 시점: 정면에서 살짝 위에서 내려다본 2D 탑다운
• 바닥 줄: 맨 아래에서 3칸 위(64칸 = 60번 줄), 좌우 가운데 / 날아다니는 적은 예외
• ★그림이 캔버스 가장자리에 닿거나 잘리지 않게 사방 2칸 이상 여백 (이번 검수에서 공격 장면 손·불꽃이 오른쪽 끝에서 잘림)
• 자홍(분홍 보라) 금지(적 공격 예고 전용), 글자·로고 금지
• 실루엣만으로 구분 가능, 색만 바꾼 구분 금지

4. 얼굴 공통 규칙 (얼굴이 있는 대상)
• 정면 양쪽 눈 같은 높이·좌우 대칭, 눈 뜬 상태(흰자·눈동자 모두 보임, 가로 한 줄 눈 금지), 사선 눈 금지
• 입은 다문 짧은 선 (벌린 입·이빨은 설명에 있을 때만)
• 표정은 눈썹 모양으로, 턱선 1칸 그림자로 얼굴이 둥글게 퍼지지 않게
• 적·보스는 귀엽거나 예쁘지 않게, 위압감 우선

5. 공통
• 16색 이내, 소환한 인물과 같은 색 계열 → 누가 부른 것인지 색과 소재만 봐도 알아봄
• 방향: 오른쪽 옆모습만(왼쪽은 게임이 반전), 바닥에 서는 것은 바닥 줄 = 맨 아래에서 3칸 위, 떠다니는 것은 예외(아래 그림자 1줄)
• 반투명 금지 → 빛·영혼 느낌은 밝은 색과 테두리 대비로 (투명도·빛 번짐은 코드가 줌)
• 빛 줄기·불꽃 튐·폭발·고리 같은 효과는 그리지 않음 (코드가 그림), 물체·생물 몸만
• 적과 구분: 위협적이지 않고 '인물의 도구·동료'로 보이게, 눈이 있으면 인물 쪽 포인트색

6. 대상·칸 수·장수 (칸 수는 Claude 결정 가안)

• 프리스트 (금빛·흰빛, 실제 종교 상징·날개 금지)
  - 기도하는 여신 형상 72칸: 프리스트 머리 위 뒤쪽에 떠 있는 작은 여신, 긴 머리·흰 옷·두 손 모음, 얼굴은 눈 감은 듯 평온(이 대상만 감은 눈 허용) / 대기 2(옷자락만 흔들림) + 모으기 1(두 손을 위로 펼침)
  - 하늘의 대종 128칸: 금빛 거대한 종, 해 모양 성표 문양, 꼭대기 고리 / 대기 1 + 울림 1(종이 옆으로 기울어짐)
  - 금빛 촛대 48칸: 바닥에 세운 세 갈래 금 촛대, 흰 초 3개 / 대기 2(촛불 모양만 바뀜)
• 화염술사 (주황 불, 7종 모두 색은 같고 모양으로 구분)
  - 불꽃 정령 32칸: 동그란 불덩이 몸에 짧은 팔, 작은 눈 2개(노랑), 머리 끝이 불꽃으로 흔들림 / 떠다니기 2 + 들이받기 1(몸을 앞으로 길게 늘임)
  - 화염 등불 40칸: 쇠틀 안에 큰 불꽃이 든 등불, 바닥에 떠 있음(사령술사 등불과 모양 다르게: 사각 쇠틀·뾰족 지붕) / 대기 2
  - 불꽃 대검 72칸: 불로 빚은 대검(광전사 대검과 같은 길이·폭, 날 전체가 불꽃 무늬), 칼끝이 오른쪽 / 대기 1 + 휩쓸기 2(비스듬히 → 가로)
• 광전사 (진홍·붉은 투기)
  - 칼무덤 칼 48칸: 땅에 비스듬히 꽂힌 낡은 대검 한 자루, 손잡이에 붉은 천, 칼날에 붉은 핏빛 무늬 / 대기 2(천 자락만 흔들림) — 붉은 돔은 코드가 그림

• 파일 이름: <대상>_<동작>_<번호>.png (대상 = goddess, greatbell, candle, spirit, firelamp, flamesword, gravesword)
• 피할 것: 자홍, 날개, 십자가 등 실제 종교 상징, 사령술사 등불과 같은 모양
