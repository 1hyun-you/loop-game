작성 2026-11-28 회차 104 (Claude)

1. 배경
• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
• 그래픽은 모두 도트로 전환 중이고, 도트는 네가 원화 없이 정해진 칸 수로 직접 찍는 방식으로 확정됨
• 이번 묶음: 화염술사 · 사령술사의 연성 무기 아이콘 14개 (레벨업 연성 카드·전투 화면 위쪽 칸에 쓰임)
• 진행 방식: 인물 1명(7개) 완성 → 저장·커밋 → 다음 (중간에 끊겨도 완성분은 남게)
• 코드는 절대 건드리지 않음. 그림만 지정 폴더에 저장하면 끝

2. 참고 파일
• 화풍 기준: assets/dot-src/berserker/gpt_dot/ (외곽선·명암·면 나누기를 같게)
• 도트 규칙: docs/DOT_STYLE.md
• 인물 그림: assets/dot-src/pyromancer, necromancer/gpt_dot/ / 소환·설치물 그림이 이미 있으면 assets/dot-src/summons/, engineer/machines/, necromancer/summons/ 모양을 따름 / 같은 규격 예: assets/dot-src/icons/base/ (있으면 화풍 맞춤)

3. 도트 규격
• 정확히 32×32 PNG, 투명 배경, 12색 이내
• 사방 2칸 여백, 그림은 가운데, 비스듬히 45도로 놓은 구도 우선(칼·화살 등)
• 테두리·카드 틀·배경 원은 그리지 않음 (게임 코드가 그림)
• 게임 화면에서 28점 크기 칸에 1배로, 카드에서는 2·3배로 표시됨 → 1배에서도 무엇인지 읽히게 굵고 단순한 형태, 세부 장식 최소
• 픽셀 1개 = 도트 1칸, 흐림·중간색 경계·반투명 금지, 글자·숫자·로고 금지
• 외곽선 바깥 1칸 가장 짙은 색(순수 검정 금지), 빛 왼쪽 위, 명암 3단계
• 자홍(분홍 보라) 금지 (적 공격 예고 전용)

4. 연성 아이콘 공통
• 연성 = 인물의 전용 무기와 다른 무기(짝 무기)를 합친 강화 무기 → 아이콘은 '그 인물이 쓰는 짝 무기' 모습
• 그 인물 색 3색을 주로 쓰고, 짝 무기를 알아볼 모양(대검·단검·활·포탑·불덩이·등불·종·덩굴)이 보이게
• 한 인물 7개는 색이 같으므로 실루엣이 서로 확실히 다르게

5. 대상 (영문 이름 = 파일 이름)
• 화염술사 연성 7 (색: 밝은 주황 #FF8A1F·불꽃 노랑 #FFD23F·불심 흰빛 #FFF4D6 — 7개 모두 주황 불이므로 모양으로 구분)
  - f_p_sword 불꽃 대검 (대검 + 화염구): 불로 빚은 대검
  - f_p_cross X자 불칼금 (단검 + 화염구): 엇갈린 불꽃 두 줄 X자
  - f_p_bow 불씨살 (장궁 + 화염구): 불로 빚은 활 + 불화살
  - f_p_spirit 불꽃 정령 (포탑 + 화염구): 동그란 불덩이 정령, 작은 노랑 눈
  - f_p_lamp 화염 등불 (영혼 등불 + 화염구): 사각 쇠틀 등불 안 큰 불꽃
  - f_p_breath 뜨거운 숨 (축복의 종 + 화염구): 열기 고리 두 겹
  - f_p_vine 불넝쿨 (가시 덩굴 + 화염구): 불꽃 넝쿨이 나선으로 감아 오름
• 사령술사 연성 7 (색: 짙은 보라 #5B2A86·아주 짙은 보라 #1F1430·영혼 청백 #9FE3FF — 해골·뼈 금지)
  - f_n_blade 넋 먹는 칼날 (대검 + 영혼 등불): 청백 기운이 빨려 드는 영혼 대검
  - f_n_slash 넋 가르기 (단검 + 영혼 등불): 칼날 선 하나 + 뒤따르는 청백 칼날 선
  - f_n_arrow 꿰뚫는 혼살 (장궁 + 영혼 등불): 청백 영혼 화살
  - f_n_tomb 묘비 (포탑 + 영혼 등불): 금 간 비석 + 위 영혼 불꽃
  - f_n_wisp 도깨비불 (화염구 + 영혼 등불): 흔들리는 푸른 도깨비불
  - f_n_bell 조종 (축복의 종 + 영혼 등불): 낡고 금 간 검은 종
  - f_n_hand 망자의 손 (가시 덩굴 + 영혼 등불): 땅에서 솟은 청백 손 두 개
