[도트 제작 요청 묶음 O3] 아이콘 — 연성 무기 14개 (궁수 · 엔지니어)
작성 2026-11-28 회차 104 (Claude)

1. 배경
• 게임: '회귀의 들판' — 휴대폰 세로 화면용 탑다운 액션 웹 게임 (뱀파이어 서바이버즈와 비슷한 방식)
• 그래픽은 모두 도트로 전환 중이고, 도트는 네가 원화 없이 정해진 칸 수로 직접 찍는 방식으로 확정됨
• 이번 묶음: 궁수 · 엔지니어의 연성 무기 아이콘 14개 (레벨업 연성 카드·전투 화면 위쪽 칸에 쓰임)
• 진행 방식: 인물 1명(7개) 완성 → 저장·커밋 → 다음 (중간에 끊겨도 완성분은 남게)
• 코드는 절대 건드리지 않음. 그림만 지정 폴더에 저장하면 끝

2. 참고 파일
• 화풍 기준: assets/dot-src/berserker/gpt_dot/ (외곽선·명암·면 나누기를 같게)
• 도트 규칙: docs/DOT_STYLE.md
• 인물 그림: assets/dot-src/archer, engineer/gpt_dot/ / 소환·설치물 그림이 이미 있으면 assets/dot-src/summons/, engineer/machines/, necromancer/summons/ 모양을 따름 / 같은 규격 예: assets/dot-src/icons/base/ (있으면 화풍 맞춤)

3. 도트 규격
• 정확히 32×32 PNG, 투명 배경, 12색 이내
• 사방 2칸 여백, 그림은 가운데, 비스듬히 45도로 놓은 구도 우선(칼·화살 등)
• 테두리·카드 틀·배경 원은 그리지 않음 (게임 코드가 그림)
• 게임 화면에서 28점 크기 칸에 1배로, 카드에서는 2·3배로 표시됨 → 1배에서도 무엇인지 읽히게 굵고 단순한 형태, 세부 장식 최소
• 픽셀 1개 = 도트 1칸, 흐림·중간색 경계·반투명 금지, 글자·숫자·로고 금지
• 외곽선 바깥 1칸 가장 짙은 색(순수 검정 금지), 빛 왼쪽 위, 명암 3단계
• 자홍(분홍 보라) 금지 (적 공격 예고 전용)

4. 연성 아이콘 공통
• 연성 = 인물의 전용 무기와 다른 무기(짝 무기)를 합친 강화 무기 → 아이콘은 '그 인물이 쓰는 짝 무기' 모습
• 그 인물 색 3색을 주로 쓰고, 짝 무기를 알아볼 모양(대검·단검·활·포탑·불덩이·등불·종·덩굴)이 보이게
• 한 인물 7개는 색이 같으므로 실루엣이 서로 확실히 다르게

5. 대상 (영문 이름 = 파일 이름)
• 궁수 연성 7 (색: 연두 #9BD94A·활 나무 갈색 #7A5530·화살 흰빛 #F2F7E6)
  - f_a_crescent 초승달촉 화살 (대검 + 장궁): 넓은 초승달 칼날을 촉으로 단 화살
  - f_a_knife 사냥칼 던지기 (단검 + 장궁): 회전하는 사냥칼 + 곡선 잔상
  - f_a_perch 매 횃대 (포탑 + 장궁): 횃대 위에 앉은 매
  - f_a_fire 불화살 (화염구 + 장궁): 촉에 불이 붙은 화살
  - f_a_barb 미늘 줄화살 (영혼 등불 + 장궁): 미늘 촉 화살 + 뒤에 이어진 줄
  - f_a_whistle 우는살 (축복의 종 + 장궁): 촉 대신 구멍 뚫린 우는살 + 작은 소리 고리
  - f_a_thorn 가시줄 화살 (가시 덩굴 + 장궁): 가시 덩굴이 감긴 화살
• 엔지니어 연성 7 (색: 구리 #B8652F·철회 #5E6670·용접 파랑 #4FA8FF)
  - f_e_mech 대검 기계병 (대검 + 포탑): 대검 든 땅딸막한 두 다리 로봇
  - f_e_drone 칼날 드론 (단검 + 포탑): 프로펠러 2개 + 칼날 단 드론
  - f_e_ballista 쇠뇌 포대 (장궁 + 포탑): 받침 위 큰 쇠뇌
  - f_e_furnace 용광로 (화염구 + 포탑): 굴뚝 달린 작은 화로 + 쇳물 빛
  - f_e_torch 용접 토치 (영혼 등불 + 포탑): 꺾인 팔 끝 파란 토치 불꽃
  - f_e_bell 경보종 (축복의 종 + 포탑): 쇠 기둥 위 종 + 망치 팔
  - f_e_wire 철조망 발사기 (가시 덩굴 + 포탑): 철조망 감긴 원통
