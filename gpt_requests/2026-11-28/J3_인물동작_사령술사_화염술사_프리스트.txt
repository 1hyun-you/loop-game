3. 도트 규격 (공통)
• 픽셀 1개 = 도트 1칸, 투명 배경(바닥 타일 제외), 흐림·중간색 경계·반투명 금지
• 색 수: 인물 16 · 잡몹 12 · 정예 12 · 우두머리 16 · 수문장·마왕 24 · 배경 조각 8 이내
• 외곽선 바깥 1칸 가장 짙은 색(순수 검정 금지), 빛 왼쪽 위, 명암 3단계
• 시점: 정면에서 살짝 위에서 내려다본 2D 탑다운
• 바닥 줄: 맨 아래에서 3칸 위(64칸 = 60번 줄), 좌우 가운데 / 날아다니는 적은 예외
• ★그림이 캔버스 가장자리에 닿거나 잘리지 않게 사방 2칸 이상 여백 (이번 검수에서 공격 장면 손·불꽃이 오른쪽 끝에서 잘림)
• 자홍(분홍 보라) 금지(적 공격 예고 전용), 글자·로고 금지
• 실루엣만으로 구분 가능, 색만 바꾼 구분 금지

4. 얼굴 공통 규칙 (얼굴이 있는 대상)
• 정면 양쪽 눈 같은 높이·좌우 대칭, 눈 뜬 상태(흰자·눈동자 모두 보임, 가로 한 줄 눈 금지), 사선 눈 금지
• 입은 다문 짧은 선 (벌린 입·이빨은 설명에 있을 때만)
• 표정은 눈썹 모양으로, 턱선 1칸 그림자로 얼굴이 둥글게 퍼지지 않게
• 적·보스는 귀엽거나 예쁘지 않게, 위압감 우선

5. 대상별 설명

• 사령술사 (64칸, 지금 팔레트 그대로)
  - 인상: 영혼을 거두는 음울한 술사, 동작은 느리고 조용하게
  - 공격 3장 (영혼 등불): 등불을 든 팔을 몸 쪽으로 당김 → 등불을 앞으로 내밀어 듦(팔이 쭉 뻗음) → 등불을 천천히 내림
  - 궁극기 2장 (거대 망령): 등불을 머리 위로 높이 듦 → 등불 뚜껑을 다른 손으로 연 자세 (망령은 코드가 그림)
  - 사망 4장: 공통 규칙대로, 등불은 옆에 떨어져 놓임
  - 특수 2장 (등불 거두기): 정면, 등불을 가슴 앞에 두 손으로 감싸 쥠 → 고개를 숙이고 등불을 끌어안음
  - 피할 것: 얼굴이 다시 흰 가면처럼 밝아지는 것

• 화염술사 (64칸, 지금 팔레트 그대로)
  - 인상: 불을 다루는 자신만만한 젊은 마법사
  - 공격 3장 (화염구): 지팡이를 뒤로 젖히고 빈손에 불씨를 모음 → 지팡이를 앞으로 휘둘러 겨눔 → 지팡이를 세우며 한쪽 입꼬리 미소
  - 궁극기 2장 (화염 해방): 지팡이를 두 손으로 머리 위에 가로로 들고 웅크림 → 두 팔을 활짝 벌리고 가슴을 젖힘
  - 사망 4장: 공통 규칙대로, 뾰족 모자가 떨어져 옆에 놓임
  - 특수 1장 (불 거두기): 정면, 손바닥을 위로 펴고 불씨를 바라봄
  - 피할 것: 모자 끝 꺾임이 사라지는 것

• 프리스트 (64칸, 지금 팔레트 그대로)
  - 인상: 기도로 지키는 온화한 사제
  - 공격 3장 (축복의 종): 손종을 든 손을 위로 → 손종을 앞으로 흔듦(종이 기울어짐) → 손종을 반대쪽으로 흔듦
  - 궁극기 2장 (하늘의 대종): 두 손을 모아 하늘을 올려다봄 → 두 팔을 하늘로 높이 뻗음 (하늘의 종은 코드가 그림)
  - 사망 4장: 공통 규칙대로, 베일은 그대로, 손종은 옆에 놓임
  - 특수 2장 (기도): 정면, 눈을 감지 않고 아래를 보며 두 손을 가슴 앞에 모음 → 무릎을 살짝 굽힌 기도 자세 (멈춰 있을 때 반복)
  - 피할 것: 실제 종교 상징, 날개

6. 동작 방향·장수 공통 (Claude 결정 가안)
• 공격 = 오른쪽 옆모습 3장 (왼쪽은 게임이 좌우 반전): 준비 → 휘두름·발사 → 마무리
• 궁극기 = 정면(아래) 2장: 모으기 → 터뜨리기
• 사망 = 정면(아래) 4장: 비틀거림 → 무릎 → 쓰러짐 → 엎드림(마지막 장은 망토만 펼쳐진 채 가만히)
• 특수 동작 = 인물마다 아래 적힌 장수
• 이펙트(불꽃·빛·잔상·화살 궤적)는 그리지 않음 — 게임 코드가 따로 그림. 무기·몸 동작만
• 모든 장: 서 있기 그림과 같은 얼굴·색·망토·키, 발바닥 60번 줄 고정(쓰러지는 장면은 몸이 바닥 줄 위에 눕게), 사방 2칸 여백
