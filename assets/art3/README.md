# art3 공유 이미지 묶음

- 용도: 소환수·상호작용 물체·특수 효과·대화 초상의 손그림 판타지 화풍 통일.
- 제작: 내장 이미지 생성 기능으로 투명 원화 제작 후 프레임 경계 절취·크기 정규화·WebP 최적화.
- 좌표 기준: `manifest.json`. 투명 여백이 포함된 공유 이미지 하나를 여러 스프라이트에서 사용.
- 재생성: 이미지 및 좌표 수정 후 `node dev/pack-art3.cjs`, `sh build.sh` 실행.

## 표시·호환 규칙

- 기존 `SPR`의 논리 크기·반전·피격·정예 외곽선 유지.
- `pj_wind`, `dbeam`은 기존 논리 폭/높이로 채워서 표시. 그 밖의 그림은 종횡비 유지.
- 공통 구슬 `ball`의 기존 색상 변형 보존.
- 보석 크기 3종, 봉인석·강화 화염·전용 화살은 공통 그림 별칭을 사용하며 각 원래 표시 크기 유지.
- 초상 로딩 전에는 기존 도트 초상 사용. 로딩 후 현재 대화의 글자 진행 상태를 바꾸지 않고 그림만 갱신.
- 새 이미지를 적용하지 못한 경우 기존 도트 렌더러로 대체.
