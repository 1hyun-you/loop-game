# 게임 기획서

Oct 22, 2026 · @유일현

모바일 세로형 탑다운 액션, 고른 능력이 매 판 플레이 방식을 바꾸는 성장 분기 중심 게임. 4·5단계 결정 가안 통합본이며, 미정 항목은 "미정" 또는 "제작 중 결정"으로 표기.

## 개요

핵심 재미는 성장 분기: 고른 능력이 매 판 플레이 방식을 바꾸고, 페이즈는 빌드를 시험하는 무대, 서사는 분위기 보강 역할.

| 구분 | 내용 |
| --- | --- |
| 장르 | 탑다운 액션, 뱀파이어 서바이벌 규칙 일부 채용 |
| 플랫폼 | 모바일 전용, 세로형 고정, 한 손 터치 조작, 웹 캔버스 방식 |
| 배포 | 웹 배포(GitHub Pages), 스토어 등록 없음 |
| 테마 | 판타지 모험 (검과 마법, 던전·마왕 계열) |
| 분위기 | 명암 혼합: 기본 밝은 모험, 보스·특정 페이즈에서 어두운 전환 |
| 성장 철학 | 오버워치 특성 선택식: 최적 선택지 없이 모든 선택지가 매력적이고 선택마다 다른 플레이 스타일 형성 |
| 목표 수준 | 완성형 개인 작품: 무기·효과 10\~15종 이상, 판당 15\~20분, 효과음·배경음, 메뉴·설정·기록 |
| 성능 기준 | 적 동시 300\~500, 60 FPS 유지 |
| 제작 기간 | 11주, 29\~43회차 (제작 프로젝트 착수일부터) |

## 판 구조

한 판 일반 12\~15분·마지막 판 13\~17분(2026-11-04 하향, 이전 15\~20분), 장면 전환 없이 열린 들판에서 페이즈를 돌파하며 진행. 준보스 4인을 판마다 1인씩 처치해 기록을 누적하고, 마지막 준보스를 잡은 판에서 곧바로 마왕전 진행.

### 공간·진행

- 공간: 자유 방향형 열린 들판, 어느 방향으로 가도 지형이 이어짐, 진행도는 페이즈 돌파 수로 측정
- 페이즈 진행: 기본 페이즈 순서는 판마다 무작위 자동 진행, 경로 선택 강요 없음
- 사전 예고: 페이즈 진입 전부터 지형·색감·배경음 등 환경 변화로 다음 페이즈 성격 암시
- 미채용: 갈림길·포탈·균열·선택 버튼 등 대놓고 보이는 경로 선택 장치
- 곁가지 사건: 동굴 입구·잠든 거대 몹·봉인된 문 등 플레이어 주변 임의 생성, 간접 신호로 성격 암시, 무시 가능, 건드리면 고난도·보상 페이즈

### 보스 구성

| 구분 | 등장 방식 | 비고 |
| --- | --- | --- |
| 중간 보스 | 별도 보스 미제작, 잡몹의 엘리트 버전으로 등장 (6단계 변경, 사양은 아래 핵심 시스템 반영분) | 수량 6단계 결정 |
| 준보스 4인 | 판마다 미처치 준보스 중 1인 등장 (회귀 진행형) | 사문의 수문장 4인 확정 (3단계, 아래 콘텐츠 확장 반영분) |
| 마왕 | 마지막 준보스를 처치한 판에서 마왕성 출현, 같은 판에서 마왕전 | 최종 스토리 보스, 고유 패턴 3페이즈 (3단계 확정) |

### 판 결과·승리 조건

- 준보스 처치: 판 클리어, 처치 기록이 회귀 후에도 누적
- 사망: 출발점 회귀, 판 단위 초기화, 해금·처치 기록만 유지
- 마왕전 사망: 4인 처치 기록 유지, 다음 판부터 재도전 판(페이즈 5종 후 마왕전 직행, 마왕 체력 0.65배) (3단계 확정)
- 마지막 판 길이: 준보스전 + 마왕전 중첩으로 20분 초과 우려, 4번째 문 개방 직후 마왕전 연결, 15\~20분 유지 (3단계 확정)
- 일반 엔딩: 첫 마왕 처치, 마왕이 고리에 의해 되살아나 회귀 지속
- 진엔딩: 기록 조각 전부 해금 후 시간 고리가 끊어지고 마왕을 진짜 처치 (계기는 시간 고리 원인과 함께 결정)
- 첫 마왕전 도달: 최소 4판

### 진엔딩 이후 콘텐츠

- 기본 축: 고난도 단계형, 진엔딩 후 단계 해금, 단계마다 적 강화 + 보상 증가
- 선택 축: 도전 조건형, 단계 위에 얹어 켜고 끌 수 있는 조건 (예: 근접 무기만, 선택지 2개, 체력 회복 없음)
- 불쾌감 방지 원칙: 조건은 강제하지 않고, 조건마다 보상 배율 또는 전용 해금을 붙여 제약이 아닌 목표로 인식되도록 설계
- 조건 목록·보상 수치는 제작 중 결정

## 성장 구조

성장 요소는 무기 + 보조 효과 + 전직 특성의 2층 + 전직 특성형. 판 단위 초기화, 판을 넘어 남는 것은 해금 항목뿐.

| 요소 | 규칙 |
| --- | --- |
| 레벨업 | 경험치 → 레벨업 → 3지선다, 무기·보조 효과 획득·강화 |
| 무기 분기 | 같은 무기를 여러 번 강화한 시점마다 플레이 방식 분기 2지선다 (예: 화살 관통/분열, 회전검 반경 확대/투척) |
| 보조 효과 특수화 | 혼합형: 무기와 동일 규칙의 강화 단계별 2지선다 분기 + 일부 보조 효과는 연계 유물 재료 겸용 |
| 조합 | 유물형: 무기 2\~3개 또는 무기 + 보조 효과 조합 시 추가 효과 발동, 기존 무기 유지 |
| 칸 수 | 무기 5칸, 보조 효과 5칸, 분기·전직 특성은 칸 미점유 별도 영역 |
| 다시 뽑기·제외 | 판당 2\~3회 |
| 전직 | 판 한정: 2번째 페이즈 돌파 후 전직 제단 출현, 판 종료 시 초기화, 후보 3종 중 2종 주력 계열·1종 무작위 (2단계 확정) |
| 전직 후 | 직업 고유 규칙·궁극기 적용, 직업 계열 무기 후보 비중 1.4배·피해 +10%, 1개 페이즈 돌파 후 2차 전직 |
| 영구 성장 | 해금형: 판 결과로 새 무기·전직·선택지가 다음 판 후보에 추가, 능력치 강화형 미채용 |

미채용: 말드할라식 3층 성장, 양면형 보조 효과, 캐릭터 레벨 주기 분기.

## 조작·페이즈

한 손 단일 입력 원칙, 추가 버튼 없음. 페이즈 기믹은 전투 위에 겹치는 방식.

### 조작 (표준형)

- 이동: 가상 조이스틱, 기본 유동형(화면 어디서나 생성), 설정에서 고정형 전환
- 공격: 자동 발동
- 위치 기반: 특정 지점 이동·체류로 기믹 처리
- 정지 입력: 멈춰 있으면 충전·특수 동작 (2단계 확정: 조이스틱에서 손 뗀 채 0.6초 정지 시 궁극기 발동, 설정에서 자동 발동 전환)
- 미채용: 손 떼기 순간 발동, 제스처 입력

### 페이즈 풀

- 구성: 기본형(물량전·느린 전개·휴식 등), 전투형(보스전·물량 폭주 등), 기믹형(레이드식 패턴·퍼즐·방탈출형)
- 기믹 융합 원칙: 기믹 진행 중에도 일반 몹 출현·공격 지속, 맥락 없는 등장 금지
- 판마다 풀에서 일부만 투입, 순서 무작위
- 완성본 풀 12종·판당 7\~8종 투입 (3단계 확정, 아래 콘텐츠 확장 반영분)
- 1단계 풀(0.3): 기본형 들판의 물결(140초 버티기)·고요한 언덕(80초, 출현 감소, 회복의 샘), 전투형 몰아치는 무리(120초 물량 폭주)·오우거 전열(오우거 대장 처치), 기믹형 봉인석(구역 4곳 체류 해제, 구역 안 적 둔화), 5종 전부 무작위 순서 투입, 전부 돌파 시 판 완료
- 페이즈 사이 6초 예고 구간: 다음 페이즈 이름 표시·화면 색감 전환

## 서사 개요

시간 고리형 골격만 확정, 원인·세부 설정은 제작 중 결정. 서사는 분위기 보강 위치로 작업량 최소화.

- 세계관 골격: 마왕성 주변 시간 왜곡, 쓰러질 때마다 출발점 회귀, 기억만 누적
- 원인 검토 후보: 봉인 붕괴형, 마왕 결계형, 봉인 붕괴 + 공동 수감 설정 (마왕이 고리를 역이용하는 설정은 비선호)
- 확인 필요: 현 설정에 막연한 미흡함 느낌 있음, 원인 결정 시 재검토
- 전달 방식: 판 시작·보스 등장·판 종료 시 초상화 포함 짧은 대사창 + 판 결과로 기록 조각 해금, 도감에서 열람
- 분량: 최소형, 완성본 기록 조각 10개 내외, 초상화 3종(주인공·마왕·조력자 1명)
- 진엔딩 연결: 기록 조각 전부 해금이 고리를 끊는 조건
