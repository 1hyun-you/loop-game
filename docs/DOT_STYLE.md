# 도트 그림 규칙 (회차 99 신설, Claude 작성)

모든 도트 그림(인물·몬스터·보스·배경·이펙트·초상화)의 일관성 기준. Claude가 도트를 찍을 때와 GPT 원본을 받을 때 모두 이 문서를 따름.
칸 수(그림 크기)는 시야 결정에 따라 바뀔 수 있음 → 3장 표만 고치면 됨.

## 1. 기본

- 시점: 정면에서 살짝 위에서 내려다본 2D 탑다운 (머리·몸 앞면이 함께 보임)
- 칸 크기 통일: 한 화면 안의 모든 그림은 같은 칸 크기. 확대는 정수배(2배·3배)만, 1.5배 같은 비정수 확대·회전 금지
- 빛 방향: 왼쪽 위 고정 (밝은 면 = 왼쪽·위, 그림자 = 오른쪽·아래)
- 금지: 반투명, 그라데이션, 흐림, 안티에일리어싱(경계를 흐리게 하는 중간색 점)

## 2. 선과 색

- 외곽선: 바깥 1칸, 순수 검정 금지 → 그 물체의 가장 짙은 색(인물은 보조색 계열)
  - 빛 받는 쪽 외곽선은 한 단계 밝게 해도 됨 (선택적 외곽선)
- 명암: 재질마다 3단계 (그림자·기본·밝은 면), 가장 밝은 점(하이라이트)은 금속·눈·보석에만
- 색 수: 인물 16색 이내, 잡몹 12색 이내, 배경 조각 8색 이내
- 인물 색: DESIGN 10장 3색(주색 넓게 / 보조색 테두리·그림자 / 포인트색 작게) 그대로
- 망토: 인물 색 계열로 인물마다 다르게 (흰 형체만 진홍 #9E1B32), 찢긴 모양 금지
- 자홍(분홍 보라) 금지: 적 공격 예고 전용
- 화면 층: 배경 = 가장 어둡고 채도 낮음·외곽선 없음 / 적 = 중간 채도·어두운 외곽선 / 플레이어·이펙트 = 가장 선명

## 3. 크기 (칸 수)

- 회차 99 결정: 화면 시야 1.2배 넓게 + 모든 그림 칸 수 1.25배 (미리보기 체감 확인 후 확정)
- ★기준 기기 = 일반 바 형태 휴대폰(S23, 화면 폭 360점·배율 3). 실제 보이는 폭은 config viewWidth(400, 시뮬레이션용)가 아니라 input.js battleZoom(폭 ÷ 390 × 1.4, 1.15~2.05)이 정함 → S23 기준 지금 약 280, 1.2배 = 약 335 (battleZoom 계수 1.4 → 약 1.17로 조정 예정)
- 칸 수는 그 크기 그대로 찍는 것이라 확대가 아님 → 1.25배여도 칸이 뭉개지지 않음
- 칸 수는 짝수로 맞춤 (가운데 정렬·좌우 반전 시 한 칸 어긋남 방지)

| 대상 | 칸 수 (가로×세로) |
| --- | --- |
| 인물 | 40×40 |
| 잡몹 | 박쥐 20 · 슬라임 30 · 해골 병사 40 · 오우거 60 |
| 정예 | 같은 몬스터의 약 1.5배 칸 수를 짝수로 (박쥐 30 · 슬라임 46 · 해골 60 · 오우거 90) |
| 우두머리 | 80 |
| 수문장 | 120 |
| 마왕 | 160 |
| 배경 조각 | 40×40 (이어 붙였을 때 이음매가 보이지 않게) |
| 초상화 | 상반신 160×160 |

- 화면 표시: 1칸 = 게임 좌표 1, S23 기준 지금 약 3.9픽셀 → 1.2배 후 약 3.2픽셀 (정수가 아니라 칸 폭이 3·4픽셀로 섞일 수 있음, 지금도 같은 상태)
- 화면 폭 대비 인물(40칸): 약 40/335 ≈ 12% / 폴드 펼친 화면은 확대 상한(2.05) 때문에 더 넓게 보임

## 4. 형태

- 인물 비율: 약 2.5등신, 머리 = 몸 높이의 약 40% (작은 화면에서 표정·머리 모양이 보이도록)
- 발 위치: 그림 아래쪽에서 2칸 위에 고정 (그림자 자리), 좌우 중심은 그림 가운데
- 실루엣: 검은색으로 채워도 누구인지 알아볼 수 있어야 함 (머리 모양·무기·망토로 구분)
- 고아 점 금지: 혼자 떨어진 1칸짜리 점은 지우거나 이어 붙임
- 곡선 계단: 1-1-2-3처럼 길이가 고르게 변해야 함, 1-3-1-2처럼 들쭉날쭉 금지

## 5. 움직임

- 방향: 4방향 (아래·위·옆 3세트 + 옆은 좌우 반전), 대각선은 나중
- 서 있기 2장: 몸 전체가 1칸 오르내림 (숨쉬기)
- 걷기 4장: 발 닿음 → 지나감 → 반대발 닿음 → 지나감, 프레임마다 실루엣 크기 거의 일정
- 맞음: 그림 없음, 코드로 번쩍임·밀림
- 공격 자세 2~3장 / 궁극기 1~2장 / 사망 3~4장 / 인물 특수 동작 (GPT_REQUESTS 도트 전환 장)
- 망토는 이동 방향 반대쪽으로 1~2칸 늦게 따라옴

## 6. 파일

- PNG, 투명 배경, 칸 1개 = 픽셀 1개 (확대하지 않은 원본으로 저장)
- 이름: <대상>_<동작>_<방향>_<번호>.png (예: berserker_walk_down_1.png), 확인용 확대본은 _preview 붙임
- GPT 원본: assets/dot-src/<대상>/ (가로 약 512, 0.5MB 이하) / 완성 도트: assets/dot/<대상>/
