## 1. 게임 구조 원칙 (회차 64 확정)

- 3층 구조: 무기 / 인물 / 성장
- 무기: 공용. 어느 인물이 골라도 동작·수치 동일. 인물이 무기 자체를 바꾸는 특혜 금지
- 인물: 전용 무기 1개 + 고유 규칙 + 궁극기. 인물 효과는 버프·추가 효과로만 작동
- 성장: 분기(Lv 3) → 각성(Lv 5) → 연성(전용 무기 + 짝 무기, 인물 세계관에 맞게 번역)
- 인물형 전환 [확정·미구현]: 기존 직업 전직을 인물 전환으로 변경. 표기 '이름 · 부제(직업)'. 이름·서사 컨셉은 추후 확정('영혼 빙의'는 가안)
- 인물 간 중복 금지: 같은 계열 인물도 플레이 감각이 확실히 달라야 함
- 용어: 인물별 무기는 '전용 무기'(기존 '상징 무기'·'기본 무기' 표현 폐기, 코드 식별명은 당분간 유지)
- 0.53 직업형 기본 무기 변형 5종 폐지 [확정·미구현]: 군주 방패 밀치기·기술자 지뢰·시간술사 시간 지연장·소환사 영혼 사슬·프리스트 심판의 빛 → 원래 공용 무기로 복귀
- 무기 이름: 현행 유지, 지나치게 특정 인물 느낌이 나는 이름만 회의 중 지적 시 변경
- 제외 무기 8종(회전검·창·철퇴·부메랑 도끼·투척 단검·폭탄·번개·회오리)은 신규 인물 후보
- 기간 제한 없음, 완성도 우선

### 기획 판단 기준 (사용자 선호)

- 외워야 하는 규칙, "여기선 되는데 저기선 안 됨" 같은 예외 규칙 지양
- 인물 차이가 플레이에서 강하게 체감돼야 함
- 모든 무기 공통 적 표식 체계 지양 (개별 무기 단위 상태 효과는 허용)
- 단순 수치 조정보다 메커니즘·판정 변경 선호
- 개연성: 모든 효과는 이유가 설명돼야 함 (예: 무거운 대검이라 느리지만 길게 벰, 근거 없는 무적 금지)
- 역할 겹침 분리: 효과끼리 역할이 겹치면 한쪽에만 배치, 단 결정 위계(인물 정체성 > 인물 각성 > 무기 발현·무기 각성 > 보조 효과)를 따라 하위 쪽을 조정하고 상위 정체성은 제한하지 않음 (회차 69)
- 효과 크기 비례: 가벼운 동작은 가벼운 효과, 중간 동작은 중간 효과, 큰 동작은 큰 효과
- 밸런스: 피해 집계 수치만 보고 조정 금지, 밀치기·멈칫·감속 등 다른 무기가 때릴 시간을 벌어 주는 가치까지 복합 평가

## 3. 판 구조 [현행]

- 열린 들판에서 장면 전환 없이 페이즈를 차례로 돌파. 진행도 = 페이즈 돌파 수
- 판 길이(참고 지표): 일반 판 약 12~15분, 마지막 판 약 13~17분 (무적 완주 기준, 0.56 평균 737초)
- 페이즈: 판마다 무작위 순서 자동 진행, 경로 선택 장치 없음, 페이즈 사이 6초 예고 구간(이름 표시·색감 전환)
- 강함 판정: 플레이어가 강하면 다음 페이즈가 위험 변형, 휴식형은 습격 변형(판당 최대 1회)
- 시작 무기 3지선다
- 초반 완화: 첫 2페이즈 적 체력·출현 0.8배, 경험치 1.25배
- 몬스터 성장: 1분마다 체력 +45%, 공격력 +7%, 이동 속도 +4%
