## 1. 게임 구조 원칙

- 3층 구조: 무기 / 인물 / 성장
- 무기: 공용. 어느 인물이 골라도 동작·수치 동일. 인물이 무기 자체를 바꾸는 특혜 금지
- 인물: 전용 무기 1개 + 고유 규칙 + 궁극기. 인물 효과는 무기 자체의 동작·수치를 바꾸지 않음
  - 고유 규칙 적용 유형: 연성형(기본, 전용 무기 + 연성 무기에만) / 전체형 / 대상형 / 주변형 / 자신형 / 제약형, 컨셉에 맞게 인물마다 선택 (몸 효과 = 받는 피해·이동·밀려남은 예외, 처치 결과 기반 규칙은 컨셉 예외)
  - 제약형 조건: 불쾌하거나 불편하게 느껴지면 안 됨, 제약이 곧 그 인물의 리듬·재미
  - 멈춤·자리 강제 인물에는 경험치 획득 보조 수단 1개씩
- 성장: 전용 무기 = 발현(Lv 3) → 무기 각성(Lv 5) / 일반 무기 = Lv 5 연성(짝 무기 Lv 5) / 인물 쪽 = 인물 선택 후 돌발 사건 클리어 시 인물 각성 (4장)
- 인물 표기: '이름 · 부제(직업)', 이름·서사 컨셉은 추후 확정 (현재 문서의 인물명은 직업명)
- 인물 간 중복 금지: 같은 계열 인물도 플레이 감각이 확실히 달라야 함 (한 판 = 한 인물이라, 겹침은 플레이 감각이 같아질 때만 점검)
- 용어: 인물별 무기 = '전용 무기', 짝 무기 = 연성 재료가 되는 일반 무기 / 옛 용어 대응: 직업 → 인물, 전직 → 인물 선택, 2차 전직 → 인물 각성, 완성형 → 무기 각성, 곁가지 사건 → 돌발 사건
- 캐릭터 몸 동작: 공통 기본 동작 5~6종(휘두르기·내지르기·시전·회전·던지기 등)을 8인물이 공유, 연성 무기는 몸 동작 추가 없음(효과는 적·무기 쪽 장면으로)
- 캐릭터가 스스로 이동하는 효과 금지 (돌진·순간 이동 등)
- ★플레이어 선택권: 조작은 이동뿐 → 적을 플레이어 쪽으로 끌어오는 자동 효과 금지(전 인물), 근접 유도는 '다가가면 보상' 방식만
- 제외 무기(도끼·창·철퇴·폭탄·번개·얼음·회전검·부메랑 도끼 등)는 향후 인물·무기 후보 → 연성에 끌어오지 않음
- 기간 제한 없음, 완성도 우선

### 기획 판단 기준 (사용자 선호, 상세는 REWORK_MEETING 1장 설계 원칙)

- 외워야 하는 규칙, "여기선 되는데 저기선 안 됨" 같은 예외 규칙 지양
- 인물 차이가 플레이에서 강하게 체감돼야 함, ★인물 정체성 최우선
- 모든 무기 공통 적 표식 체계 지양 (개별 무기 단위 상태 효과는 허용)
- 단순 수치 조정보다 메커니즘·판정 변경 선호
- 개연성: 모든 효과는 이유가 설명돼야 함, 근거 없는 무적 금지
- 겹침 위계: 인물 정체성 > 인물 각성 > 무기 발현·무기 각성·연성 > 보조 효과, 겹치면 하위 쪽 조정
- 효과 크기 비례: 가벼운 동작은 가벼운 효과, 큰 동작은 큰 효과 / 조건·사건이 클수록 변화·보상도 커야 함
- 밸런스: 피해 집계 수치만 보고 조정 금지, 밀치기·멈칫·감속 등 시간을 벌어 주는 가치까지 복합 평가

## 3. 판 구조

### 진행 [현행]

- 열린 들판에서 장면 전환 없이 페이즈를 차례로 돌파. 진행도 = 페이즈 돌파 수
- 판 길이(참고 지표): 일반 판 약 12~15분, 마지막 판 약 13~17분 (무적 완주 기준, 0.58 평균 688초)
- 페이즈: 판마다 무작위 순서 자동 진행, 경로 선택 장치 없음, 페이즈 사이 6초 예고 구간(이름 표시·색감 전환)
- 강함 판정: 플레이어가 강하면 다음 페이즈가 위험 변형, 휴식형은 습격 변형(판당 최대 1회)
- 시작 무기 3지선다, 무기 획득은 레벨업 선택지 (바닥 줍기 폐기)
- 초반 완화: 첫 2페이즈 적 체력·출현 0.8배, 경험치 1.25배
- 몬스터 성장: 1분마다 체력 +45%, 공격력 +7%, 이동 속도 +4%

### 적

- [현행] 잡몹 10종, 정예(크기 1.5배·체력 8배·금색 테두리 + 특수 능력 1개, 페이즈당 1~2회, 처치 시 보물 상자)
- ★잡몹 체력 방향 = 섞기 (회차 90 확정) [0.60 가안 수치: 해골 병사 34·분열 젤리 30·돌진 멧돼지 48·방패병 60·오우거 70, 단단한 적 경험치 +1, 출현 비중 하향 → 실측 약 26~28%]
  - 약한 떼(박쥐·슬라임 등)는 무기 한 방에 처치 → 쓸어 버리는 시원함 유지
  - 단단한 적(해골 병사급 이상)은 2~4번 맞아야 처치 → '묶거나 건 뒤 때려 터뜨리는' 연계가 실제로 발동
  - 제어 효과(묶기·멈추기)는 피해를 약하게 두고, 마무리는 무기로 때려야 터지게 함
  - 단단한 적 비율 가안: 화면 속 적의 약 20~30% (밸런스 단계 조정)
  - 참고(현행 초반 체력): 박쥐 5, 슬라임 9, 해골 병사 18, 오우거 70 / 무기 1회 피해 약 15~20
- 제어 공통: 멈칫·묶임 등은 수문장·마왕 절반
- 사문의 수문장 4인 [현행]: 1인 처치마다 문 1개 개방, 4문 개방 시 마왕성 출현

- 흰 형체 = 용사의 빈자리(망토가 표식), 1페이즈 끝 동료가 흰 형체와 겹쳐지며 망토를 이어받아 다음 용사 후보로 등장 (= 인물 선택)
- 망토: 모든 인물 초상화·인게임 그림에 처음부터 포함, 공통 색 1가지 고정 + 인물별 무늬·장식 차별화, 찢기지 않음
- 오프닝 컷신(약 20초): 원정대 vs 마왕 → 원정대 승리 → 어둠 속 손가락이 용사를 가리키고 튕김 → 용사만 지워지고 망토 낙하 → 화면 일그러짐·깨짐·시간 되감김 → 들판 재조립, 망토 아래 흰 형체가 일어나 그대로 조작 시작 / 첫 실행 자동 재생, 이후 건너뛰기·메뉴 다시 보기
- 손 등장 연출: 화면 위쪽이 종이처럼 찢어지고 그 틈으로 손목까지만 들어와 엄지·중지로 튕긴 뒤 빠져나감, 틈은 즉시 메워짐 / 사람 손과 악마 손의 중간, 적인지 편인지 모를 중립적 인상 (검은 손·뼈 손 금지)
- 사망 시: 어둠 속 손가락 튕김 + 되감김(약 1초)으로 처음 들판 복귀 (도와주는 존재처럼 보이게)
- 손의 주인 정체(심심풀이로 가지고 노는 존재)는 반전 전까지 숨김, 얼굴·몸 비노출, 손가락·튕김 소리만 반복
- 마왕 대면 3단계
  - 1차: 마왕 압도적으로 강함 → 짧은 시간(예: 20~30초) 안에 압도, 죽기 직전 손가락이 나타나 튕기며 되감김
  - 2차: 적정 강도 마왕 처치 → 평화가 온 듯한 짧은 가짜 엔딩 → 갑자기 손가락 튕김으로 처음
  - 3차: 처치 시 놀이판 반전 — 화면 전체가 페이드 아웃되며 지금까지의 공간이 거대한 놀이판(체스판)이었음이 드러남, 이후 다시 손가락 튕김 (이후 스토리 추후)
- 보스: 세계관 최강을 이름으로 박지 않고 고유 이름을 가진 보스, 놀이판 반전 존재는 광대 + 체스판 + 웃는 가면 컨셉(이름 추후), 보스는 각자 독립 컨셉·방식·패턴
- [보류] 광대 이후 회귀·흰 형체 이어 가기, 진엔딩·용사 유품, 2차 대면 마왕 약화 체감 보완, 망토 색 변화 연출, 서사 접목(첫 사망 손 튕김 시연·판 시작 '회귀 N회'·들판 회귀 흔적 — Claude 추천안)
