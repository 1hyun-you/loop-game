# 프리스트 — 기도로 빛을 모아 지키고 벌하는 사람

## 1. 고유 규칙

- 정체성 구도: 기본 = 치유·보호 반 + 공격 반 / 인물 각성 1 = 공격 / 인물 각성 2 = 보호 쪽 + 공격 유지, '보호가 곧 공격'
- 유형: 연성형
- 기도 = 빛을 모으는 장치(스스로 피해 없음), 평소 천천히·멈추면 2배, 단계마다 이펙트 변화, 무기는 계속 발동
- 3단계 차는 순간 0.3초 모으기 모션 → 축복 일제 발동: 전용·연성 무기가 간격 무관 한꺼번에 강화 발동(범위 +50%·피해 2배) + 빛 파동 연출(피해 없음)·종소리 + 보호막 2초
- 머리 위 여신 형상: 작은 반투명 기도하는 여신(캐릭터 키 1~1.2배, 머리 뒤쪽 위), 가리면 링으로 교체, 기도의 출처·단계 표시 겸함
  - 평소 희미한 기도 자세·숨 쉬듯 흔들림, 모일 때 빛 입자 '윙' 빨려 듦, 1·2단계 밝기·빛무리 증가
  - 3단계 동작 세부: 나중에 (5장)

## 2. 전용 무기 축복의 종

- 기본: 3초마다 반경 140(0.9초) 음파 고리, 피해 + 멈칫 0.2초 / 투사체 정화는 일제 발동 종소리(세 겹)에만
- 무기 각성은 일제 발동 때만 강화(범위 +50%·피해 2배), 평소 동일
- 발현 A 잔향: 맞은 적이 떨리고 0.5초 뒤 같은 적에게 약한 울림 1번·30%·멈칫 없음
  - → 무기 각성 A 공명: 맞은 적마다 0.3초 뒤 반경 70 작은 고리·50% + 멈칫, 1번만 번짐, 일제 발동 때 반경 105
- 발현 B 뻗는 울림: 적 많은 방향 부채꼴 120도·반경 260·피해 +20%·멈칫 동일
  - → 무기 각성 B 겹울림: 부채꼴 세 겹 0.2초 간격·각 70%·마지막 겹 살짝 밀어냄, 일제 발동 때 범위 +50%·피해 2배

## 3. 궁극기·인물 각성

- 기본 궁극기 하늘의 대종: 거대한 빛의 종이 적 무리 위로 떨어짐(큰 피해 + 1초 기절) → 6초 머물며 1초마다 울림(종 1.5배 + 멈칫, 범위 안 받는 피해 -30%·초당 체력 2% 회복) → 마지막 울림 때 일제 발동 1회
- 인물 각성 1(공격) 넘치는 기도
  - 플레이어 규칙: "서서 기도하면 더 크게 터진다"
  - 움직이는 중 3단계 도달 → 바로 3단계 크기로 터짐 / 서서 기도 중 3단계 → 계속 모아 4단계에서 더 크게(3단계 후 4초, 범위 +100%·피해 3배), 모으는 도중 움직이면 그 순간 3단계 크기로
  - 궁극기 여신 강림: 일제 발동 1초 간격 3번, 기본 크기
- 인물 각성 2(보호) 맡기는 기도
  - 서서 기도하는 동안 반경 100 안 가장 가까운 적 1마리에게 0.8초 간격 작은 빛 번개(종 기본 피해 80% + 멈칫 0.2초), 움직이면 멈춤·서면 재개, 일제 발동 때 번개 없음
  - 궁극기 심판: 여신이 날개처럼 감쌈, 이동 불가·피해 무효 2초, 화면 적에게 빛 번개 0.2초 간격 10줄기, 적 많은 곳부터

## 4. 연성 7종

- 번역 원칙: 빛(금빛·흰빛)·빛의 문양·촛대·빛 사슬 소재, 새 규칙 추가 없이 7종 모두 일제 발동 때 강화(범위 +50%·피해 2배, 커지고 밝아짐)
- 색: 7종 모두 금빛 → 모양(검·십자·화살 갈래·촛대·불꽃·등불·사슬 원)으로 구분
- 어울리지 않는 것: 하늘에서 떨어지는 큰 종(기본 궁극기), 여신이 직접 싸움, 빛 번개(맡기는 기도·심판), 벽·장막, 되갚기(개연성 없음), 순수 보호

- 성검 (축복의 종 + 대검)
  - 규칙: 빛의 검이 곁을 휩쓸고, 벤 적 수만큼 빛 조각이 머리 위 여신에게 날아가 기도가 빨리 참
  - 업그레이드: 휩쓸기 + 기도 충전 (가까이서 싸우면 기도가 빨리 차는 보상 — '멈추면 2배'와 다른 길)
  - 수치: 1.25초마다·사거리 86(0.6초)·110도·피해 19·밀쳐냄 대검 기본 / 벤 적 1마리당 기도 +2%(한 번 휘두를 때 최대 +8%)
- 십자 긋기 (축복의 종 + 단검)
  - 규칙: 빛 칼날이 적 몸에 세로·가로 두 줄을 그어 십자를 새기고, 가로 획은 양옆 적까지 길게 그어짐 (십자 문양 사용자 확인)
  - 업그레이드: 1회 → 2회 + 가로 획이 양옆 적까지
  - 수치: 0.9초마다·사거리 220(1.5초)·세로 14·0.15초 뒤 가로 60%·가로 획 좌우 각 50(0.3초) 안 적 함께
- 갈라지는 빛살 (축복의 종 + 장궁)
  - 규칙: 빛 화살이 적에 맞으면 빛이 갈라져 가까운 적 둘에게 작은 빛살로 뻗음 (프리즘처럼 옆으로)
  - 업그레이드: 1마리 → 맞은 적 + 2마리
  - 수치: 1.0초마다·사거리 300(2.0초)·피해 16 / 갈라진 빛살 반경 120(0.8초) 안 2마리·각 50%
- 금빛 촛대 (축복의 종 + 포탑 설치)
  - 규칙: 곁에 금빛 촛대가 세워지고, 촛불 빛 범위 안에 들어온 적은 빛에 그을려 계속 피해 (쏘지 않음)
  - 수치: 4초마다 1개·최대 3개·유지 10초 / 빛 반경 70(0.5초)·0.5초마다 6
- 성화 (축복의 종 + 화염구)
  - 규칙: 흰 불꽃 덩이(화염구 모양)를 던져 터뜨리고, 기도가 차오를수록 불꽃이 커짐
  - 업그레이드: 기도 단계에 따라 폭발 범위가 커짐 (일제 발동 뒤 다시 작아졌다 커지는 순환)
  - 수치: 1.2초마다·사거리 260(1.7초)·피해 18·폭발 반경 기도 0단계 35 → 1단계 45 → 2단계 55(0.4초)·불붙음 없음
- 정화의 등불 (축복의 종 + 영혼 등불)
  - 규칙: 빛의 등불이 가까운 적의 어둠을 빨아들여, 빛으로 바꿔 프리스트 체력을 채움
  - 업그레이드: 흡수 → 회복
  - 장면: 금빛 등불, 적에게서 검은 기운이 줄기를 타고 오다 등불에서 빛으로 바뀌어 프리스트에게 스며듦
  - 수치: 1마리·사거리 140(0.9초)·0.25초마다 5·준 피해의 10% 체력 회복
- 결박진 (축복의 종 + 가시 덩굴)
  - 규칙: 적이 몰린 곳 바닥에 빛 문양 원 → 원 둘레에서 빛 사슬 여러 줄이 솟아 원 안 적들을 한꺼번에 감아 묶음 (끌어당김 없음, 결계로 남지 않음)
  - 수치: 1.3초마다·사거리 200(1.3초) 안 가장 몰린 곳·원 반경 60(0.4초)·최대 4마리·피해 15·묶임 0.5초

### 구현 메모 (0.67, 회차 98 · 사용자 확인 전 가안)

- 기도 속도: 이동 중 9초·멈추면 4.5초에 3단계, 단계마다 여신 밝기·빛무리 증가, 빛 입자가 여신에게 빨려 듦
- 축복 일제 발동: 그 순간 전용·연성 무기를 각 1번 추가 발동(원래 발동 간격은 그대로), 기도는 0으로 / 금빛 촛대가 이미 3개면 세워진 촛대가 범위 +50%·피해 2배로 한 번 크게 타오름
- 보호막 2초: 그 동안 받는 피해를 전부 막음 (문서 '보호막 2초'를 피해 무효로 해석)
- 투사체 정화: 일제 발동 종소리 범위(종 반경 × 1.5) 안 적 탄환 소멸 / 빛 파동은 피해 없음
- 무기 각성 A 공명은 잔향을 대체(잔향 울림은 각성 뒤 없음) / 겹울림 각 겹 = 뻗는 울림 피해(+20%)의 70%, 마지막 겹 밀어냄 70(프리스트 쪽에서 바깥으로)
- 뻗는 울림 방향: 12방향 중 부채꼴 안 적이 가장 많은 쪽
- 넘치는 기도: 4단계까지 모으는 동안 기도 표시는 가득 찬 상태로 깜빡임, 0.3초 모으기 동작 동안은 기도가 차지 않음
- 하늘의 대종: 떨어지는 자리 = 반경 320 안 주변 적이 가장 많은 적, 반경 150, 0.4초 뒤 낙하·낙하 피해 = 종 1번 피해 × 4·밀쳐냄 160(바깥으로), 울림은 종 피해 × 1.5, 회복은 울림마다 2% / 대종 안에 있을 때만 받는 피해 -30%
- 여신 강림·대종 마지막 울림의 일제 발동은 기도를 비우지 않고 보호막도 주지 않음
- 맡기는 기도 번개: 0.8초 동안 서 있어야 첫 번개, 대상이 없으면 대기 / 심판: 번개 1줄기 반경 40·종 1번 피해 × 3, 대상 = 화면 안 주변 적이 가장 많은 적
