# 도적 — 빠른 암살자

이관 2026-11-26 (회차 90 문서 반영, REWORK_MEETING 3·4장 확정본) · 구현 전 확정 기획 · 수치는 전부 가안(밸런스 단계 조정)
- 공통 구조·성장 용어·색 규칙: `docs/DESIGN.md` / 연성 작성 원칙·판단 기록: `FUSION_GUIDE.md` / 회의 원문: `docs/archive/`

## 1. 고유 규칙

- 유형: 제약형 + 연성형
- 무기 칸 3개(전용 무기 포함, 기본 5칸)
- 그림자 연격 — 플레이어 규칙 "치명타가 나면 그림자가 나타나 거든다"
  - 단검 = 한 번 더 긋기 / 연성 무기 = 무기마다 한 번 더 또는 추가 동작, 추가 동작은 어울리는 무기에만(필수 아님, 꼭 그림자 기술일 필요 없음)
  - 치명타는 단검·연성 무기에만, 일반 무기 치명타 없음
  - 기본형은 1번만 (그림자 긋기에서 치명타가 나도 이어지지 않음)
- 밸런스 주의: 칸 3개라 만렙·연성 도달이 매우 빠름 → 치명타 확률·그림자 피해 무작정 상향 금지, 치명타 피해 2배는 과함

## 2. 전용 무기 단검

- 기본: 0.9초마다 사거리 220(1.5초) 안 가장 가까운 적 1회 긋기·피해 14, 몸 동작 없음(그림자만 움직임, 적 쪽 상처 이펙트)
- 발현 A 쌍단검: 공속 2배·간격 0.45초, 회당 피해 소폭 감소
  - → 무기 각성 A 그림자 난무: N번째 발동마다 사거리 안 적 최대 5체를 0.08초 간격 차례로 긋기·각 100%
- 발현 B 긴 선: 공속 그대로, 선이 대상 뒤로 40 이어져 선 위 적 모두, 피해 소폭 증가 가능
  - → 무기 각성 B 그림자 균열: 5번째 공격마다 균열 2.5초·폭 40, 첫 가르기 200% + 0.3초마다 25%, 큰 가르기 치명타 시 그림자가 같은 가르기 반복, 균열 다단 히트는 치명타 없음
- 무기 각성 공통 모습(가안): 단검이 검게 물들고 그림자 잔상

## 3. 궁극기·인물 각성

- 기본 궁극기 그림자 잠행: 2초 피격 없음(1.5초와 비교)·이동 +50%, 스친 적(반경 60) 표식, 종료 시 표식 적 전원 확정 치명타 2배
- 인물 각성 A
  - 규칙 강화: 그림자 연격 연속 최대 3번(추가 동작형은 같은 추가 동작 최대 3번), 단계마다 그림자 피해 +20% 누적, 3번째는 붉은 X자(반경 60, 3단계 피해 기준)
  - 궁극기 그림자 분신: 분신 2명 8초, 전용·연성만 따라 함, 피해 40%, 분신도 치명타 판정
- 인물 각성 B
  - 규칙 강화: 늦게 터지는 상처 — 그림자가 그은 자리(추가 동작 포함)에 붉은 상처 선, 1초 뒤 1.8배로 터짐, 터지기 전 또 치명타 시 겹쳐 함께 터짐(최대 3겹)
  - 궁극기 일섬: 화면 가로지르는 거대한 한 줄·폭 80, 확정 치명타 3배, 0.4초 정적 뒤 상처 동시 폭발 → 4초 단검 집중(다른 무기 멈춤·단검 간격 절반·단검 피해 +N% 고정)

## 4. 연성 7종

- 도구 방향: 닌자 도구(쿠나이·쇠사슬·연막탄 등) 허용 — 도적 자기 도구라 '다른 무기 종류 금지' 예외, 그림자 연출 필수 아님
- 용어: '수리검' 표기 폐지(일반 인식상 쿠나이 모양), 별 모양 회전 날 = 표창, 고리 손잡이 단도 = 쿠나이

- 흑풍 (단검 + 대검)
  - 규칙: 가까운 적 곁 바닥에서 그림자가 솟아 부채꼴로 휩쓸고 밀쳐냄
  - 업그레이드: 가까운 적 무리 두 곳에서 동시에 솟음
  - 수치: 1.25초마다·사거리 220(1.5초)·부채꼴 110도·피해 19·밀쳐냄 대검 기본, 치명타 한 번 더
- 그림자 표창 (단검 + 장궁)
  - 규칙: 도적 그림자에서 별 모양 표창이 튀어나와 회전하며 일직선으로 날아가 지나는 적 모두 벰
  - 수치: 1.0초마다·사거리 300(2.0초)·폭 24·피해 16·관통, 치명타 한 번 더
- 대역 통나무 (단검 + 포탑 설치)
  - 규칙: 10초마다 도적 자리에 연기와 함께 도적 두건·망토 자락을 두른 가시 통나무가 나타나고 도적은 1.5초 반투명(무적 아님·잠시 표적에서 벗어남)
  - 유인: 통나무 주변 반경 120(0.8초) 안 적만 통나무를 도적으로 알고 공격, 멀리 있는 적은 그대로 도적 추적
  - 반격: 공격받으면 슝 한 바퀴 회전(반경 55·피해 10·0.6초에 1번까지, 회전 애니메이션 필수)
  - 끝: 8번 맞거나 8초 뒤 터지며 쿠나이 10자루 사방 폭발
  - 치명타 방식: 미정 → 5장
- 기폭찰 쿠나이 (단검 + 화염구, 사용자 원안)
  - 규칙: 부적을 붙인 쿠나이가 돌지 않고 곧게 날아가 가장 가까운 적 발아래에 꽂히고 0.5초 뒤 폭발 (그림자 표창과 날아가는 모습 구분)
  - 업그레이드: 꽂힐 때 멈칫 0.2초(수문장·마왕 0.1초)
  - 수치: 1.2초마다·사거리 260(1.7초)·반경 35·피해 18, 불붙음 없음, 치명타 한 번 더
- 그림자 도둑 (단검 + 영혼 등불)
  - 규칙: 그림자 실이 적 그림자를 빨아들임
  - 업그레이드: 적이 죽으면 가까운 적으로 실이 옮겨 감
  - 치명타 추가 동작(1초에 1번 판정): 그림자를 뜯어내 적 0.8초 굳음
  - 수치: 1마리·사거리 140(0.9초)·0.25초마다 5
- 숨죽인 파문 (단검 + 축복의 종)
  - 규칙: 소리 없는 어두운 파문
  - 업그레이드: 퍼졌다 되돌아오며 한 번 더(50%)
  - 치명타 추가 동작: 파문 안 적 최대 5마리 등 뒤에 그림자가 동시에 나타나 긋기
  - 수치: 3초마다·반경 140(0.9초)·피해 축복의 종 기본·멈칫 0.2초
- 올가미 (단검 + 가시 덩굴)
  - 평소: 짝 무기 기본(1.3초마다·사거리 200(1.3초)·1마리·피해 15·묶임 0.5초)
  - 치명타 추가 동작: 덩굴이 가까운 적 2마리를 더 꿰어 엮음 → 한곳으로 당김(최대 40, 적끼리 모으는 방향·플레이어 쪽 아님) → 그림자가 한 번에 그음

## 5. 구현 직전 확인

- 대역 통나무 치명타 방식: 후보 A 두 바퀴·B 두건 넘기기(적끼리 공격)·C 터진 자리 그림자 긋기, '나중에 생각'
- 그림자 도둑·숨죽인 파문: '그냥저냥 괜찮음' 판정(회차 84), 구현 전 다시 봄

## 6. 불채택·보관 (재제안 금지)

- 인물 거부: 질주, 흘리기, 3초 주기 숨기·무적, 처치 시 연쇄, 급소 노리기 → 암살, 쌍 일섬, 난도질, 3연속 분신 잔류, '단검만' 규칙(연격 집중·영구 단검만·일섬 뒤에만)
- 인물 보관: 3번째 연격 대안(배후 올려 베기·휘감기·격자 베기), 투척 단검·표창
- 연성 불채택: 잠복 그림자·꽂아 둔 단검(포탑 설치), 그림자 휩쓸기 등 뒤형·그림자 처형·그림자 대역·부채살 칼자국·되돌아오는 큰칼, 대검 닌자 도구 방향 5개, 올가미 이름 '엮어 긋기'
- 연성 애매 보관: 떠다니는 단검·표식 칼날 / 보관: 그림자 쏜살, 연막 화염, 그림자 가시
- 옛 이름: 그림자 수리검 → 그림자 표창, 기폭찰 수리검 → 기폭찰 쿠나이, 그림자 묶기 → 올가미, 그림자 휩쓸기 → 흑풍
