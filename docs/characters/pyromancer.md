## 1. 고유 규칙

- 유형: 연성형
- 화염구·연성 무기에 맞은 적이 불붙음, 추가 요소 없음 (옮겨붙음·번짐 삭제)
- 불 지속 3초·매초 화염구 피해 10%(낮게), 몬스터 체력 패치 때 재조정
- 불붙음은 화염술사 전용 상태 (공용 무기·다른 인물 연성에 화상 추가 금지)
- 컨셉: 화염을 다루는 느낌, 속도로 몰아붙이기 안 어울림

## 2. 전용 무기 화염구

- 기본: 가장 가까운 적에게 화염구·작은 폭발, 1.2초마다·사거리 260(1.7초)·폭발 반경 35·피해 18
- 발현 A 큰 불꽃: 폭발 반경 +60%
  - → 무기 각성 A 불기둥: 4번째 발동마다 불기둥 1.5초·반경 50·0.3초마다 40%·기둥 안 적 계속 불붙음
- 발현 B 불의 창: 일직선 관통·피해 +30%
  - → 무기 각성 B 폭렬 창: 3번째 발동마다 박힌 자리 1초 뒤 폭발·반경 90·250%
- 무기 각성 공통 모습: 지팡이 끝 불꽃 확대, 화염구 불꽃 꼬리

## 3. 궁극기·인물 각성

- 기본 궁극기 화염 해방: 화염술사 중심 큰 폭발(화면 절반·무기 기준 2배), 범위 안 적 전부 불붙음
- 인물 각성 A 불 거두기
  - 규칙 강화: 불붙은 적이 죽으면 불꽃이 돌아와 몸 주위를 돌고 다음 화염구에 실림(최대 5개, 개당 크기·반경 +15%·피해 +10%)
  - 궁극기 불사조: 몸 주위 불꽃이 모여 불사조, 화면 3번 가로지름, 총 6초, 지나간 적 1.5배 + 불붙음, 끝나면 불꽃 5개 가득
- 인물 각성 B 불티
  - 규칙 강화: 불붙은 적을 화염구·연성 무기로 또 맞히면 불티가 통통 3번 튀며 불을 옮김(튈 때마다 반경 90 안 불 안 붙은 가장 가까운 적, 불붙음 + 화염구 피해 20%)
  - 궁극기 거대 불덩이: 적에서 적으로 10번 튀며 튐마다 반경 80·화염구 피해 250%·불붙음, 적 많은 쪽 우선
- 인물 각성 A·B 전체: 애매 → 5장

## 4. 연성 7종

- 번역 원칙: 불을 짝 무기 모양으로 빚어 다룸, 7종 전부 불붙음
- 색 주의: 7종 모두 주황 불 → 색은 같게 두고 모양(칼·X자·활·정령·등불·고리·넝쿨)으로 확실히 구분
- 어울리지 않는 것: 속도로 몰아붙이기·연발, '불붙은 적을 또 맞히면' 추가 효과(인물 각성 B 영역), 스스로 쏘는 장치(엔지니어 영역)

- 불꽃 대검 (화염구 + 대검)
  - 규칙: 불로 빚은 대검이 앞에 떠올라 넓게 휩쓸고 밀어냄
  - 업그레이드: 무게 없는 불칼이라 대검보다 길고 넓게 휩쓺
  - 장면: 마법사 앞 허공에 불꽃 대검이 생겨 크게 휩쓸고 불꽃 궤적을 남기며 흩어짐
  - 수치: 1.25초마다·사거리 130(0.9초)·150도·피해 19·밀쳐냄 대검 기본·불붙음
- X자 불칼금 (화염구 + 단검)
  - 규칙: 불꽃 칼날이 적 몸에 엇갈린 두 줄을 그어 X자로 태움
  - 업그레이드: 1회 긋기 → 엇갈린 2회
  - 수치: 0.9초마다·사거리 220(1.5초)·첫 줄 14·0.2초 뒤 둘째 줄 60%·불붙음
- 불씨살 (화염구 + 장궁)
  - 규칙: 불로 빚은 활이 불화살을 쏘고, 화살은 멀리 날수록 바람을 먹고 커져 강해짐 (갈라지거나 튀지 않음)
  - 업그레이드: 단일 1발 → 먼 적일수록 크고 강한 화살 (가장 먼 적 우선)
  - 수치: 1.0초마다·사거리 300(2.0초) 안 가장 먼 적·피해 16 → 날아간 거리에 따라 최대 180%·화살 폭 24 → 최대 40·불붙음
- 불꽃 정령 (화염구 + 포탑 설치)
  - 규칙: 곁에 작은 불꽃 정령이 생겨나 둥둥 떠서 자리를 지키고, 다가온 적에게 '확' 달려들어 몸으로 들이받아 불붙인 뒤 제자리로 돌아옴 (쏘지 않음)
  - 업그레이드: 포탑은 한자리에서 쏘기만 함 → 정령이 직접 덮치고 불붙음까지
  - 장면: 손바닥만 한 불덩이 정령, 떠 있을 때 불꽃이 일렁임 → 들이받는 순간 불꽃이 확 번짐 → 되돌아옴 (새 모양 제외 — 불사조와 구분, 대포 모양 비선호)
  - 수치: 4초마다 1마리·최대 3마리·유지 10초 / 지키는 반경 160(1.1초) / 1.2초마다 들이받기·피해 12·불붙음
- 화염 등불 (화염구 + 영혼 등불)
  - 규칙: 불꽃 등불에서 불줄기 두 가닥이 뻗어 가까운 적 둘을 태우고, 오래 쬘수록 뜨거워짐
  - 업그레이드: 1마리 → 2마리 + 이어진 시간에 따라 피해 증가
  - 장면: 곁에 뜬 등불에서 불줄기가 휘어 이어짐 → 오래 이어질수록 줄기가 굵고 하얗게 달아오름
  - 수치: 2마리·사거리 140(0.9초)·0.25초마다 5·이어진 1초마다 피해 +25%(최대 2배)·불붙음
- 뜨거운 숨 (화염구 + 축복의 종)
  - 규칙: 숨을 내쉬듯 몸에서 열기 고리가 두 번 퍼지고, 두 번째가 더 멀리 퍼짐
  - 수치: 3초마다·첫 고리 반경 140(0.9초)·피해 종 기본·멈칫 0.2초 / 0.3초 뒤 둘째 고리 반경 200(1.3초)·60%·멈칫 없음 / 둘 다 불붙음
- 불넝쿨 (화염구 + 가시 덩굴)
  - 규칙: 발밑에서 불꽃 넝쿨이 솟아 적을 휘감고, 묶인 동안 조이며 태움 (다리부터 몸통까지 감아 오르는 모션, 기둥 모양 아님)
  - 업그레이드: 한 번 찌르기 → 묶인 동안 계속 조임(다단) + 묶임 시간 증가
  - 수치: 1.3초마다·사거리 200(1.3초)·처음 피해 15 + 묶인 동안 0.25초마다 4·묶임 1초·불붙음

## 6. 불채택·보관 (재제안 금지)

- 옛 이름: 불꽃 활 → 불씨살, 불꽃 숨결 → 뜨거운 숨, 불꽃 넝쿨 → 불넝쿨
