# 궁수 — 멈춰 서서 겨누는 사냥꾼

이관 2026-11-26 (회차 90 문서 반영, REWORK_MEETING 3·4장 확정본) · 구현 전 확정 기획 · 수치는 전부 가안(밸런스 단계 조정)
- 공통 구조·성장 용어·색 규칙: `docs/DESIGN.md` / 연성 작성 원칙·판단 기록: `FUSION_GUIDE.md` / 회의 원문: `docs/archive/`

## 1. 고유 규칙

- 유형: 제약형 + 연성형 + 자신형
- 멈춤 사격: 이동 중 발동 없음 (전용·연성만)
- 정지 중 공속 증가 (전용·연성만)
- 정지 중 경험치 흡수 범위 +60% (멈춤 인물의 경험치 보조 수단)

## 2. 전용 무기 장궁

- 기본: 멈춰 있을 때 가장 가까운 적에게 화살, 1.0초마다·사거리 300(2.0초)·피해 16, 정지 공속 +80%(실제 0.55초)
- 발현 A 연사: 한 번에 2발·0.1초 간격
  - → 무기 각성 A 속사 연발: 5번째 발동마다 1.5초 연달아 사격·초당 10발·각 50%·가장 가까운 적 추적, 시위를 빠르게 당기는 동작
- 발현 B 꿰뚫기: 사거리 끝까지 관통·피해 +15%
  - → 무기 각성 B 거대 화살: 4번째 발동마다 폭 30·화면 끝까지 관통·250%·밀쳐냄
- 무기 각성 공통 모습: 은빛 시위, 화살 깃 빛 꼬리

## 3. 궁극기·인물 각성

- 기본 궁극기 사냥 개시: 하늘로 쏜 화살이 화면 절반 범위에 쏟아짐(무기 기준 2배) → 5초간 이동 중에도 전용·연성 발동, 정지 공속 보너스 유지 (하늘 화살 장면은 이 궁극기에만)
- 인물 각성 A 매의 눈
  - 규칙 강화: 정지 공속 보너스가 서 있는 시간에 따라 상승(1초 +80% → 3초 +150%)
  - 궁극기 매의 시선: 4초 화면 전체 적 이동 -50%(수문장·마왕 25%) + 정지 공속 보너스 즉시 최대
- 인물 각성 B 치고 빠지기
  - 규칙 강화: 움직이다 멈춘 직후 첫 발동이 부채꼴 3발 + 150%
  - 궁극기 화살 폭풍: 제자리에서 돌며 3초 사방 난사·초당 12발·각 70% → 4초간 모든 발동에 첫 발동 강화

## 4. 연성 7종

- 번역 원칙: 연성 무기는 전부 화살 기본 + 사냥꾼 도구 보조(돌팔매 제외), 실제 활쏘기·사냥으로 설명 가능한 효과만(초능력 금지)
- 7종 공통: 멈춰 있을 때만 발동 + 정지 공속 +80% 적용
- 조준 분배: 가장 가까이 온 적(초승달촉·가시줄) / 가장 먼 적(우는살) / 가장 큰 무리(불화살) / 140 안 적(미늘 줄화살) / 가까이 온 2마리(사냥칼) / 매 횃대(매가 직접)

- 초승달촉 화살 (장궁 + 대검)
  - 규칙: 대검 날처럼 넓은 초승달 칼날을 촉으로 단 화살, 맞은 적 몸에 큰 칼자국, 칼날 폭 안에 붙어 있던 적도 함께 베임 (첫 적에서 멈춤, 통과 없음, 밀쳐냄 없음)
  - 업그레이드: 대검 곁 베기 → 멀리서 큰 칼날로 베기
  - 수치: 1.25초마다·사거리 220(1.5초)·칼날 폭 50·피해 19·최대 3마리
  - 점검: 거대 화살(통과·밀쳐냄)과 구분
- 사냥칼 던지기 (장궁 + 단검)
  - 규칙: 가까이 온 적 2마리에게 허리의 사냥칼을 던져 그음, 칼은 회전하며 날아가 상처 선을 남기고 바닥에 꽂혔다 사라짐 (화살로 '긋기' 불가 → 보조 수단 사냥칼)
  - 업그레이드: 1마리 → 2마리
  - 수치: 0.9초마다·사거리 160(1.1초)·각 피해 14
- 매 횃대 (장궁 + 포탑 설치)
  - 규칙: 멈춰 서 있으면 곁에 횃대가 세워지고 매가 앉음, 매는 가까이 온 적에게 날아가 할퀴고 돌아옴 (매사냥 도구, 이미 세운 횃대의 매는 궁수가 움직여도 싸움)
  - 수치: 4초마다 1개·최대 3개·유지 10초 / 매 1.2초마다·반경 180(1.2초)·피해 12
- 불화살 (장궁 + 화염구)
  - 규칙: 적이 가장 많이 몰린 곳 한가운데에 불화살을 꽂아 터뜨림
  - 업그레이드: 가장 가까운 적 1마리·작은 폭발 → 가장 큰 무리를 골라 노림·큰 폭발
  - 장면: 불붙은 화살이 곧게 날아가 무리 한가운데 바닥에 꽂힘 → 화염구 모양 불덩이가 터짐 (하늘에서 떨어지지 않음)
  - 수치: 1.2초마다·사거리 300(2.0초)·폭발 반경 60(0.4초)·피해 18·불붙음 없음
- 미늘 줄화살 (장궁 + 영혼 등불)
  - 규칙: 가까이 온 적에게 줄 달린 미늘 화살을 박아, 줄이 이어진 동안 미늘이 계속 파고듦 / 그 적이 쓰러지면 줄을 되감아 다음 적에게 바로 다시 박음
  - 업그레이드: 등불 줄기는 대상이 죽으면 끊김 → 되감아 곧바로 다음 적
  - 장면: 궁수와 적 사이 팽팽한 가는 줄, 0.25초마다 줄이 떨리며 적 몸에 작은 파고듦 표시 (잡아당기지 않음)
  - 수치: 1마리·사거리 140(0.9초)·0.25초마다 5·되감아 다시 박기 0.2초 / 궁수가 움직이면 줄이 풀림, 다시 멈추면 새로 박음
- 우는살 (장궁 + 축복의 종)
  - 규칙: 우는살이 날카로운 소리를 내며 멀리 날아가, 지나가는 길의 적을 움찔하게 하고 꽂힌 자리에서 큰 소리 고리가 퍼짐
  - 업그레이드: 종은 몸 주위 한 곳 → 멀리 꽂힌 자리의 고리 + 날아가는 길 전체 멈칫
  - 수치: 3초마다·사거리 300(2.0초) 안 가장 먼 적 / 날아가는 길 폭 40 안 적 멈칫 0.2초(피해 없음) / 꽂힌 자리 반경 140(0.9초)·피해 종 기본·멈칫 0.2초
  - 시험: 가장 먼 적 겨냥 그대로 시험
- 가시줄 화살 (장궁 + 가시 덩굴)
  - 규칙: 가시 덩굴을 감아 둔 화살이 꽂히면 덩굴이 풀려 튀어 나가, 그 적과 곁의 적들 다리를 휘감아 묶음 (땅에서 솟는 덩굴 대신 화살에 감아 둔 덩굴)
  - 업그레이드: 1마리 → 꽂힌 적 + 곁의 최대 2마리
  - 수치: 1.3초마다·사거리 200(1.3초)·가장 가까운 적·꽂힌 적 반경 60(0.4초) 안 최대 2마리 추가·피해 15·묶임 0.5초

## 5. 구현 직전 확인

- 밸런스: 거대 화살 × 매의 눈 화력 쏠림, 연성 7종 정지 공속 +80% 적용으로 우는살·불화살 간격이 크게 짧아짐
- 관찰(현행 코드): 궁수 돌파율 최저 → 구현 후 재확인

## 6. 불채택·보관 (재제안 금지)

- 인물 거부: 화살비(무기 각성), 화살 튕김
- 연성 불채택: 반달촉 화살(박힌 자리 부채꼴 베기 = 초능력), 갈래촉 화살(화살로 긋기 불가), 활 거치대(스스로 쏘는 포탑 = 엔지니어 영역), 뭉툭촉 화살, 스치는 화살
- 연성 보관: 근접 산탄 화살, 마무리 사냥, 사냥매 횃대, 밤사냥 등불, 붙잡아 두는 줄, 씨앗 화살
