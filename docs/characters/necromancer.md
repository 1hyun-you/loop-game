# 사령술사 — 영혼을 거두어 부리는 사람

이관 2026-11-26 (회차 90 문서 반영, REWORK_MEETING 3·4장 확정본) · 구현 전 확정 기획 · 수치는 전부 가안(밸런스 단계 조정)
- 공통 구조·성장 용어·색 규칙: `docs/DESIGN.md` / 연성 작성 원칙·판단 기록: `FUSION_GUIDE.md` / 회의 원문: `docs/archive/`

## 1. 고유 규칙

- 유형: 전체형 (처치 결과 기반, 컨셉 예외)
- 처치 시 40% 확률로 영혼이 떨어짐(모든 무기), 경험치 흡수 범위로 주움
- 영혼 7개마다 망령 1마리 15초 (망령 수 1.5배 방향 가안, 상한 5)
- 망령은 적에게 공격받지 않음, 망령 기술 = 날아가 할퀴기 0.8초마다 20·이동 180
- 영혼 차오름 표시 = 등불 불빛 4단계 / 누적 단계 성장 삭제

## 2. 전용 무기 영혼 등불

- 기본: 적에게서 영혼 줄기를 등불로 빨아들이며 다단 히트, 1마리·사거리 140(0.9초)·0.25초마다 5 (특정 작품 생물 모습 미사용)
- 발현 A 흡혼: 3마리
  - → 무기 각성 A 봉혼: 등불 앞 구멍으로 주변 적이 끌려 들고 약한 적은 등불 안으로 삼켜짐 (저승 아님)
- 발현 B 수혼: 등불 처치 영혼 100%·줍지 않아도 즉시 흡수·줄기 피해 +25%
  - → 무기 각성 B 폭혼: 줄기에 이어진 채 죽은 적의 영혼이 그 자리에 남아 1.2초 부풀며 빛나다 터짐·반경 60·무기 기준 150%, 터진 뒤 등불로

## 3. 궁극기·인물 각성

- 기본 궁극기 거대 망령: 등불 뚜껑이 열리며 큰 망령이 연기처럼 흘러나와 12초 곁에서 낫 휘두르기(캐릭터 3배, 1초마다 앞쪽 반원 반경 130·무기 기준 2배·밀쳐냄), 끝나면 등불로 돌아감
- 인물 각성 A
  - 규칙 강화: 작은 망령 3마리(같은 영혼 수, 마리당 40%, 무리 지어 쪼기 0.5초마다 5·이동 220, 상한 15)
  - 궁극기 영혼 방출: 작은 영혼 20개·4초·닿을 때 30
- 인물 각성 B
  - 규칙 강화: 강한 망령(영혼 10개마다, 피해·체력 2배, 유지 40초, 상한 4, 휘두르기 반경 50·1.2초마다 50·이동 130, 얇은 줄 결속·주변 250 안)
  - 궁극기 귀속: 망령이 줄에 끌려 흡수되어 사라지고 8초 강화(등불 피해 +50%·줄기 1 → 3·보호막 20%, 망령 0이면 70%)

## 4. 연성 7종

- 번역 원칙: 영혼(반투명 푸른 빛)·망령·죽음의 물건(묘비·조종) 소재, 해골 등 새 소재 금지, 이펙트 색은 사령술사 색(짙은 보라 + 영혼 청백)
- 회차 88 재구성 배분: 빨아들임(대검·가시 덩굴) / 망령 연동(포탑 설치·축복의 종) / 단독(장궁·화염구·단검)
- 세부 수치: 넋 먹는 칼날·묘비·망자의 손은 구현 직전 작성 (아래 기준 수치는 옛 초안·짝 무기 기본)

- 넋 먹는 칼날 (영혼 등불 + 대검)
  - 규칙: 영혼 대검이 휩쓸 때 벤 적들의 푸른 기운이 칼날로 빨려 들어가고, 많이 빨아들일수록 다음 휩쓸기가 넓어짐
  - 기준 수치: 1.25초마다·사거리 86(0.6초)·110도·피해 19·밀쳐냄 대검 기본 / 넓어지는 폭은 구현 직전 작성
- 넋 가르기 (영혼 등불 + 단검)
  - 규칙: 영혼 칼날이 몸을 긋고 한 박자 뒤 같은 자리에 반투명 칼날이 한 번 더 그어 넋까지 벰
  - 수치: 0.9초마다·사거리 220(1.5초)·첫 긋기 14·0.2초 뒤 넋 긋기 60%
- 꿰뚫는 혼살 (영혼 등불 + 장궁)
  - 규칙: 영혼 화살은 몸을 통과하므로 일직선 위 적을 모두 꿰뚫음
  - 업그레이드: 단일 1발 → 관통
  - 장면: 반투명 화살이 적 몸을 스르르 통과, 지나간 적 몸이 잠깐 푸르게 일렁임
  - 수치: 1.0초마다·사거리 300(2.0초)·폭 24·피해 16·관통
- 묘비 (영혼 등불 + 포탑 설치)
  - 규칙: 쏘지 않음, 근처에서 죽은 적의 영혼을 빨아들여 모으고 다 차면 묘비에서 망령이 일어나 묘비 주변을 지킴(묘비당 1마리)
  - 기준 수치: 4초마다 곁 1개·최대 3개·유지 10초 / 모으는 반경·필요 영혼 수는 구현 직전 작성
- 도깨비불 (영혼 등불 + 화염구)
  - 규칙: 푸른 도깨비불이 흔들흔들 떠가며 적을 따라가 반드시 닿고, 닿으면 크게 터짐
  - 업그레이드: 곧게 날아감 → 느리게 따라감(빗나가지 않음) + 폭발 범위 확대
  - 장면: 화염구 모양 푸른 불꽃(불 모양 유지)이 흔들리며 떠감 → 닿으면 푸른 불꽃 폭발
  - 수치: 1.2초마다·사거리 260(1.7초)·이동 초당 180·폭발 반경 55(0.4초)·피해 18·불붙음 없음
- 조종 (영혼 등불 + 축복의 종, 죽음을 알리는 종)
  - 규칙: 낡은 종이 울리면 소환된 망령들도 함께 울부짖어, 망령 곁에도 울림이 퍼짐
  - 업그레이드: 울림 한 곳 → 사령술사 + 망령 수만큼
  - 장면: 사령술사 머리 위 반투명 낡은 종 '뎅' → 망령들이 고개를 들고 울부짖으며 작은 고리
  - 수치: 3초마다·반경 140(0.9초)·피해 종 기본·멈칫 0.2초 / 망령마다 반경 60(0.4초)·50%·멈칫 0.2초
- 망자의 손 (영혼 등불 + 가시 덩굴)
  - 규칙: 땅에서 망자의 손들이 솟아 최대 3마리 발목을 움켜쥐고, 붙잡은 동안 기운을 빨아들임(다단 피해) (땅속으로 끌어내리지 않음, 끌어당김 없음)
  - 기준 수치: 1.3초마다·사거리 200(1.3초)·가장 가까운 적 + 반경 70(0.5초) 안 최대 2마리·피해 15·묶임 0.5초 / 다단 피해량은 구현 직전 작성

## 5. 구현 직전 확인

- 위 3종(넋 먹는 칼날·묘비·망자의 손) 세부 수치 작성
- 밸런스: 망령 수에 따른 화면 복잡도(반투명·작은 크기), 중저가 성능, 망령 피해 비중, 영혼 줍기와 궁극기 게이지, 도깨비불 여러 개 동시 화면 복잡도
- 기본 궁극기·인물 각성 B 궁극기 대안 보관(영혼 낚시·영혼 그물)

## 6. 불채택·보관 (재제안 금지)

- 인물 보관: 영혼 낚시·영혼 그물·영혼 휘두르기(다른 인물 재활용 가능) / 불채택: 영혼 분열·감속·영혼 뽑기·환혼
- 연성 불채택: 넋 베기(옛 대검 초안), 떠도는 비수(도깨비불과 움직임 겹침), 넋 긋기(망령 유지 증가 = 쓸데없는 부차 규칙), 영혼 탄을 쏘는 묘비
- 연성 보관: 망령들도 함께 휩쓸기, 해골 팔 휩쓸기, 베인 적 영혼이 반쯤 빠져나옴, 혼살이 잠시 망령이 됨, 처치 시 영혼 2개, 바닥 영혼이 함께 울림
