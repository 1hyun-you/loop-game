# 광전사 — 분노로 날뛰는 근접 전사

- 공통 구조·성장 용어·색 규칙: `docs/DESIGN.md` / 연성 작성 원칙·판단 기록: `FUSION_GUIDE.md` / 회의 원문: `docs/archive/`

## 1. 고유 규칙

- 유형: 연성형 + 자신형
- 투지: 피격 +15, 대검·연성 무기 피해 환산 충전(잡몹 1체 대검 1회 = +3, 정예 2배·수문장·마왕 3배 환산), 피격·명중 없으면 서서히 감소, 가득 차면 격노
- 격노: 8초 고정, 격노 중 충전 없음, 휘두르는 속도 +25%(전용·연성만), 받는 피해 -15%, 범위 확대 없음, 붉은 불길 표시
- 게이지(구현 후보): 평소 붉은 충전 → 격노 시 짙은 붉은색으로 8초 동안 줄어듦
- ★근접으로 가야 하는 인물 (연성 거리 원칙은 4장)
- 망토는 찢기지 않음

## 2. 전용 무기 대검 베기

- 기본: 부채꼴 약 110도, 사거리 86(이동 시간 약 0.6초), 1.25초마다, 피해 19, 밀쳐냄
- 발현 A 광역 베기: 각도 +45%·사거리 +25%
  - → 무기 각성 A 회오리 베기: 4번째 베기마다 1.2초 3바퀴·바퀴당 70%·이동 가능·마지막 강한 밀쳐냄
- 발현 B 무거운 베기: 동작 0.2 → 0.45초·간격 1.25 → 1.5초·사거리 +15%·피해 +20%·밀쳐냄 +20%, 칼끝 바닥 긁기 먼지 (공속 감소는 대검 무게 컨셉 예외)
  - → 무기 각성 B 찌르기: 3번째 베기마다 직선 사거리 1.6배·폭 50·220%·멈칫 0.3초·우선 조준
- 무기 각성 공통 모습: 칼날 확대·붉은 날 무늬

## 3. 궁극기·인물 각성

- 기본 궁극기 대지 분쇄: 제자리 도약 0.35초(공중 피격 없음), 착지 화면 절반 범위 무기 기준 2배, 생존 적 1.5초 기절
- 인물 각성 A 광란
  - 규칙 강화: 게이지형 격노(격노 중 충전·피격 +10, 소모 초당 8에서 1초마다 +2 가속), 휘두르는 속도 +50%·받는 피해 -25%·피해 누적 1초당 +3%(최대 +45%)·처치 회복(잡몹 0.5%·정예 3%)
  - 궁극기 광란의 포효: 1.0초 포효·주변 밀어냄·약한 피해 → 속도 +100%·받는 피해 -40%·이동 +30%·화상 2초(초당 대검 15%)·처치 시 화염 폭발 반경 60·50% (속도·화상은 전용·연성만)
- 인물 각성 B 광폭
  - 규칙 강화: 투지 가득 60, 폭주 4초(몸 1.3배 그림만·피해 +40%·범위 +20%·명중 멈칫 0.25초 — 전용·연성만, 받는 피해 -30%·밀려남 없음, 대검 속도 -15%)
  - 궁극기 분출 강타: 0.4초 전진 도약·앞쪽 140도·반경 화면 폭 40%·2배 → 핏빛 분출 3회 0.35초 간격·각 0.6배·멈칫 0.2초 → 착지 즉시 폭주

## 4. 연성 7종

- 거리 원칙: 기본은 광전사 근처에서 발동 / 짝 무기 특성상 원거리가 더 맞고 광전사다운 원거리 수단(투기)이 있으면 원거리 허용 / 근접 유도형(가까울수록 강함·대검과 엮임) 허용
- 격노 연동 시점 분리: 투지 높이(칼자국) / 격노 진입(투기살) / 격노 지속(칼무덤) / 격노 종료(고동) / 연동 없음(분화·투기 가시) / 투지 충전(피의 갈증)

- 칼자국 (대검 + 단검)
  - 규칙: 먼 적 몸에 굵게 찢긴 붉은 칼자국, 투지에 따라 굵기·피해 100~150%, 격노 중 2마리 동시
  - 수치: 0.9초마다·사거리 220(1.5초)·피해 15·밀쳐냄 대검의 40% (원거리 허용)
- 투기살 (대검 + 장궁)
  - 규칙: 붉은 투기 한 줄기가 멀리 꿰뚫고 날아감·멈칫 0.2초(수문장·마왕 0.1초), 격노 진입 순간 거대 투기살(폭 70·300%)
  - 수치: 1.0초마다·사거리 300(2.0초)·폭 24·피해 16
- 칼무덤 (대검 + 포탑 설치)
  - 규칙: 투지가 담긴 칼이 꽂혀 붉은 원형 돔이 불안정하게 흔들림, 2.5초마다 확 커짐, 격노 중 더 커지고 짙어짐
  - 수치: 평소 반경 65±5·0.5초마다 6 / 확 커짐 반경 110·피해 20·밀쳐냄 / 격노 중 반경 150·1.5초마다·1.5배·짙은 붉은색 / 4초마다 1자루·최대 3자루·유지 10초
- 분화 (대검 + 화염구)
  - 규칙: 광전사 주변 적 발밑 땅이 붉게 갈라지고 틈에서 화염구 모양 불덩이가 솟구쳐 터짐, 3곳 차례로
  - 수치: 1.2초마다·주변 반경 120(0.8초)·폭발 반경 40·피해 18 / 바닥에 남지 않음·불붙음 없음·투지 연동 없음
- 피의 갈증 (대검 + 영혼 등불)
  - 규칙: 주변 적 최대 3마리를 동시에 흡수, 가까운 적은 굵은 줄·피해 증가, 투지 충전 2배
  - 수치: 반경 140(0.9초) 안 최대 3마리·0.3초마다 마리당 8 / 60(0.4초) 안쪽 적 굵은 줄·피해 1.5배 / 격노 중 충전 없음 규칙은 그대로
- 고동 (대검 + 축복의 종)
  - 규칙: 몸에서 심장 박동처럼 붉은 고리 '쿵-쿵'(두 번째 60%), 격노 종료 순간 큰 고동
  - 수치: 3초마다·반경 140(0.9초)·피해 축복의 종 기본·멈칫 0.2초 / 큰 고동 반경 220(1.5초)·250%·밀쳐냄
- 투기 가시 (대검 + 가시 덩굴)
  - 규칙: 가장 가까운 적 발밑에서 붉은 투기 가시가 솟아 찌르고 몬스터 하단을 휘감아 붙잡는 모션(필수), 묶인 동안 대검에 베이면 터짐 추가 100% 1회 (투지 연동 없음)
  - 수치: 짝 무기 기본(1.3초마다·사거리 200(1.3초)·반경 35·피해 15·묶임 0.5초)
  - 업그레이드: 보류 → 5장

## 5. 구현 직전 확인

- 투기 가시 업그레이드: 잡몹 체력 방향 확정(회차 90, 섞기 — 단단한 적은 2~4번)에 맞춰 재검토
- 피격 유도 설계(일부러 맞게 만드는 구조, 광전사 전체 변경): 보류, 맞는 일이 적어 피격 연동 효과는 체감 미미
- 미결 수치: 광란 +100% 과다 가능성, 광폭 1.3배·1.2배 비교

## 6. 불채택·보관 (재제안 금지)

- 연성 불채택: 칼바람(대검 결합 위주), 분풀이 손도끼(도끼 종류), 울화탄(피격 연동), 포위 폭발, 분노 운석(하늘 낙하), 불덩이 던지기형 분화
- 연성 보관: 분노의 잔영, 무거운 발걸음·살기·머리 위 대검 파동(애매)·움켜쥐는 투기·물어뜯는 땅·가시 돋친 몸
- 옛 이름(회차 89 변경): 분노의 칼자국 → 칼자국, 분노의 불길 → 분화, 분노의 고동 → 고동, 분노의 가시 → 투기 가시
