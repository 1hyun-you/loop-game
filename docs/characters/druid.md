# 드루이드 — 자연의 수호자, 야수 변신

이관 2026-11-26 (회차 90 문서 반영, REWORK_MEETING 3·4장 확정본) · 구현 전 확정 기획 · 수치는 전부 가안(밸런스 단계 조정)
- 공통 구조·성장 용어·색 규칙: `docs/DESIGN.md` / 연성 작성 원칙·판단 기록: `FUSION_GUIDE.md` / 회의 원문: `docs/archive/`

## 1. 고유 규칙

- 유형: 자신형 + 연성형
- 야수 변신: 늑대로 시작, 1.5초 멈추면 반대 형태로 전환, 전환 후 4초 재전환 불가, 두 형태 모두 자유 이동
  - 늑대: 이동 +20%, 전용·연성 발동 속도 +30%
  - 곰: 받는 피해 -30%, 전용·연성 범위 +30%
- 전환 효과: 곰 = 바닥 내려찍기 충격, 늑대 = 포효(주변 적 0.5초 겁먹어 물러남)
- 연성 무기도 형태에 따라 모습 변화 (늑대 = 가늘고 빠름·초록, 곰 = 굵고 큼·갈색, 동작은 같고 모습만 다름)
- 경험치 보조 수단 불필요 (멈춤이 짧음)

## 2. 전용 무기 가시 덩굴

- 기본: 가장 가까운 적 발밑에서 솟아 휘감아 찌르고 묶음, 1.3초마다·사거리 200(1.3초)·솟는 반경 35·피해 15·묶임 0.5초(수문장·마왕 0.25초) / 늑대 = 약 1.0초 간격, 곰 = 반경 약 45
- 발현 A 얽는 덩굴: 솟는 순간 반경 70 안 최대 2마리에게 줄기가 더 뻗음, 피해 70%·묶임 동일
  - → 무기 각성 A 덩굴 덤불: 솟은 자리에 덤불 3초, 들어온 적 40%·묶임 0.5초(같은 적 1.5초에 1번), 동시 6개, 늑대 = 자주, 곰 = 넓게
- 발현 B 가시 창: 굵은 가시가 적을 꿰어 들어 올림, 피해 +50%, 들어 올림 0.4초
  - → 무기 각성 B 가시꽃: 솟고 0.3초 뒤 6방향 가시 줄기·길이 90·각 50%
- 무기 각성 공통 모습: 잎·꽃망울, 늑대 = 가늘고 빠른 초록 줄기, 곰 = 굵은 갈색 줄기

## 3. 궁극기·인물 각성

- 기본 궁극기 수호목: 뒤로 거대한 고목이 솟아(0.5초) 가지 4번 내려치기(0.4초 간격, 적 많은 곳 순서, 반경 90·무기 기준 2배·밀쳐냄) → 사라지며 잎을 흩뿌려 체력 10% 회복, 약 2.5초
- 인물 각성 A 깊어지는 야성
  - 규칙 강화: 같은 형태를 오래 유지할수록 짐승이 커지고 강해짐(6초·12초 단계 상승, 단계마다 형태 효과 +50%, 3단계 = 은빛 큰 늑대·거대 곰), 바꾸면 1단계부터
  - 궁극기 만월: 보름달 빛으로 지금 형태가 단번에 3단계, 8초 동안 바꿔도 3단계 유지, 시작 순간 전환 효과 2배
- 인물 각성 B 자연의 응답
  - 규칙 강화: 변신하는 순간 주변 땅에서 가시 덩굴 일제 분출(곰 = 원형 반경 150, 늑대 = 앞쪽 부채꼴 길이 200, 덩굴 150%·묶임 1초)
  - 궁극기 숲의 부름: 반경 200 숲이 자라 8초·자리 고정, 숲 안 적 이동 -30%, 숲 안에서 변신하면 숲 전체에서 덩굴

## 4. 연성 7종

- 번역 원칙: 자연 소재로 나눔 — 짐승 발톱(대검)·잎(단검)·새(장궁)·식충 꽃(포탑)·버섯(화염구)·뿌리(등불)·꽃(종)
- 어울리지 않는 것: 불 그대로 쓰기(숲을 태움), 변신 순간 효과(자연의 응답), 같은 형태 유지 강화(깊어지는 야성), 덤불·가시꽃(무기 각성), 거대 나무(수호목), 따라다니는 동료 짐승(불채택), 포효·내려찍기(전환 효과)

- 앞발 휩쓸기 (가시 덩굴 + 대검)
  - 규칙: 짐승 앞발 발톱 자국이 앞을 휩쓸고, 반대쪽 앞발이 이어서 한 번 더 휩쓺 (캐릭터 몸 동작 추가 없음, 발톱 자국만)
  - 업그레이드: 1회 → 좌우 앞발 2연속
  - 형태: 늑대 = 가늘고 날카로운 발톱, 곰 = 굵고 넓은 발톱
  - 수치: 1.25초마다·사거리 86(0.6초)·110도·피해 19·밀쳐냄 대검 기본 / 0.3초 뒤 둘째 70%
- 칼잎 (가시 덩굴 + 단검)
  - 규칙: 칼잎 3장이 한꺼번에 흩날리듯 날아가, 가까운 적 3마리를 한 장씩 그음
  - 업그레이드: 1마리 → 3마리 동시 (앞발 휩쓸기 '한 번 더'와 중복 회피, 회차 89)
  - 형태: 늑대 = 가늘고 빠른 초록 잎, 곰 = 넓은 갈색 잎
  - 수치: 0.9초마다·사거리 220(1.5초)·3장·장당 피해 11
- 매 강하 (가시 덩굴 + 장궁)
  - 규칙: 숲의 매가 날아올라 멀리 있는 적을 향해 낮게 곧게 내리꽂히며, 지나는 길의 적을 할퀴고 지나감 (따라다니는 동료가 아니라 한 번 날아드는 공격)
  - 업그레이드: 단일 1발 → 지나는 길 관통
  - 형태: 늑대 = 작고 날랜 매, 곰 = 큰 수리
  - 수치: 1.0초마다·사거리 300(2.0초)·폭 24·피해 16·관통
- 식충 꽃 (가시 덩굴 + 포탑 설치)
  - 규칙: 곁에 식충 꽃이 피어 적에게 독액을 뱉고, 독액은 바닥에 원형으로 잠시 남아 밟는 적에게 피해 (물기 없음, 중독 상태 없음)
  - 형태: 늑대 = 날렵한 작은 꽃, 곰 = 크고 굵은 꽃
  - 기준 수치: 4초마다 곁 1개·최대 3개·유지 10초 / 독액 0.8초마다·사거리 240(1.6초)·피해 8 / 바닥 원 반경·유지 시간·피해는 구현 직전 작성
- 포자 버섯 (가시 덩굴 + 화염구)
  - 규칙: 적이 몰린 곳 발밑에서 큰 버섯이 순식간에 부풀어 '펑' 터지며 포자 가루가 퍼짐(바로 사라짐, 상태 효과 없음) — 핵심 '불'은 숲의 수호자와 충돌해 2순위 '터진다'로
  - 형태: 늑대 = 작고 빠름, 곰 = 크고 넓음
  - 수치: 1.2초마다·사거리 260(1.7초) 안 가장 몰린 곳·반경 45(0.3초)·피해 18
- 생명 뿌리 (가시 덩굴 + 영혼 등불)
  - 규칙: 땅속 뿌리 2가닥이 가까운 적 2마리 발밑까지 뻗어, 이어진 동안 생기를 빨아들임 (휘감지 않음, 회복 없음)
  - 업그레이드: 1마리 → 2마리
  - 장면: 드루이드 발밑에서 뿌리가 땅 위로 이어져 맥박치듯 초록 빛이 흐름
  - 형태: 늑대 = 가는 뿌리, 곰 = 굵은 뿌리
  - 수치: 2마리·사거리 140(0.9초)·0.25초마다 5
- 초롱꽃 (가시 덩굴 + 축복의 종)
  - 규칙: 곁에 핀 초롱꽃이 흔들리면 꽃가루 고리가 퍼져 적을 움찔하게 하고, 꽃가루가 잠시 남아 적을 느리게 함 (소리 대신 종 모양 꽃 — 포효와 겹침 회피)
  - 업그레이드: 고리 + 잠깐 남는 감속
  - 형태: 늑대 = 작은 꽃, 곰 = 큰 꽃
  - 수치: 3초마다·반경 140(0.9초)·피해 종 기본·멈칫 0.2초 / 꽃가루 0.8초·그 안 적 이동 -20%

## 5. 구현 직전 확인

- 식충 꽃 바닥 독액 세부 수치 작성
- 작업량: 7종 모두 형태별 모습 2종 → 아트 작업량이 가장 큼 (작업량 관리 미결과 함께 판단)
- 매 강하: 동물을 부르는 장면이 '동료 야수 불채택'과 같은 결로 느껴지는지 실기기 체감 확인

## 6. 불채택·보관 (재제안 금지)

- 인물 불채택: 야성 순환 + 변신 난무, 짐승 벗 + 합일, 동료 야수(고유 규칙안), 시간술사·군주 삭제
- 연성 불채택: 불꽃 열매, 해바라기 불씨, 벌집 폭탄, 식충 꽃 물기·독 상태, 생명 뿌리 회복·회복 꽃
- 연성 보관: 내려찍기, 포효 고리, 가시 투창(창 종류), 그냥 불덩이, 흡수로 바로 회복, 잎 세 장 부채꼴
